Secondary is the default. One primary (orange) per page, for the main action only. Icon buttons get an orange badge when something is set.

List-page status filter, full width under the title. Same tab as detail pages, with a count chip after each label.

18. List toolbar: filter bar, sort, columns, export

Saved-filters button, then one box holding filter tokens and the search, with Save joined to its right end (navy when there is something to save, white and disabled otherwise). Sort and columns are icon buttons; the columns button shows the visible count and opens the column picker (19).

19. Column picker

Opens from the columns button. Find a column, tick to show, drag to reorder, pin. The first column is always shown. No density setting.

20. Card

One white card per block: 1px #E5E7EB border, 12px radius, 14/16 padding, 12px uppercase grey title. Several blocks that belong together (a side summary) go in one panel with dividers, not separate cards. On a white page, top-level sections need no card at all: title, content, then a divider. Never box inside box inside box; keep boxes for things you act on (inputs, files).

21. Upload card

While the user is attaching (before sending or accepting). 112×112 tile, 12px radius: type icon, file name (2 lines, then …), type badge bottom-left; Download bottom-right and Remove top-right show on hover. A click previews. The last tile is a dashed "Attach file"; it disappears at the limit. Above the tiles: "Files" with a red * when required (or "(optional)") and the limit in grey. Type colours: PDF red, XLS/CSV green, image purple, other grey. Tiles wrap; 5 tiles + the add tile fit one row.

22. Attachment card

Read-only files: documents the shipper shares, and files after the answer is sent. 36px type tile, name (one line, …, full name on hover), kind ("PDF", "Spreadsheet · XLSX"), then Preview and Download icon buttons (quiet grey, tooltips, always visible). A click on the card previews. Hover: orange border, soft shadow, orange name. Cards sit in a grid: 260px minimum, 360px maximum, filling left to right. 1 file = one 360px card (never full width); 2 = side by side; 4 = three and one; 6 = two rows of three.

23. Date panel

Every date filter opens this panel (from freehand-studio InvoiceDateRangeFilter). Presets on the left, one choice, marked with an orange check (not radios or checkboxes, the presets overlap). "Clear dates" only when a date is set; "Custom range" label under the presets. Right: Between / On or after / On or before, then a month calendar; today in orange; Between takes two clicks, the other two one. No "Any time" option: with nothing set the chip reads "All".
