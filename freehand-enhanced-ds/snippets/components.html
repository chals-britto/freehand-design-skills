Enhanced Studio components

Freehand V1 Enhanced Studio. Each block shows the markup to copy; styles are in the <style> block above, values in tokens.css.

1. Buttons

Secondary is the default. One primary (orange) per page, for the main action only. Icon buttons get an orange badge when something is set.

2. Status pills

List-page status filter. Pills, not tabs: they filter one list. 28px tall, count inside.

3. Badges, tags, count chip

Status badges carry meaning by tone. Exception tags inside cards stay neutral. Count chip sits next to section titles.

One dropdown per field. Options show live counts. An active dropdown turns orange with a count.

Same as the listing pages: icon button, "Sort by" list, the chosen row gets an ascending / descending toggle, "Clear sort" at the bottom.

18. List toolbar: filter bar, sort, columns, export

Saved-filters button, then one box holding filter tokens and the search. "Save" stays disabled until there is something to save. Sort and columns are icon buttons; the columns button shows the visible count and opens the column picker (19).

19. Column picker

Opens from the columns button. Find a column, tick to show, drag to reorder, pin. The first column is always shown. No density setting.
