Progress Indicator

A thin bar with a short text that shows how far a multi-step task has got. Split out of File Upload so other screens can reuse it.

Try it

Move the slider to call pdsProgress.set(el, value). “Use Figma step text” swaps in the Figma text for the nearest step (0–5).

Usage

Where it is used

File Upload shows it while a file goes through its steps. Figma has no other usage text for this component.

Text

  • Figma text per state: “0/5 steps complete”, “1/5 steps” … “4/5 steps”, “Complete”.
  • The State 0 wording differs from States 1–4 — open copy decision.

Theme

Use Dark only on dark surfaces such as --dark-bg.

Accessibility

Progress bar semantics

role="progressbar" with aria-valuemin="0", aria-valuemax="100" and aria-valuenow. The visible text is copied to aria-valuetext. progress.js sets these.

Name it

A progress bar needs a name. Pass label to build() or point aria-labelledby at the file name. Figma has no label.

Open for the accessibility pass

Dark text on #393945 is 3.4 : 1. The green fill against the Light track is 1.7 : 1 and against white 2.1 : 1 (below 3 : 1 for graphics). Kept as Figma for now.

Open issues

  • Copy is inconsistent: State 0 “0/5 steps complete”, States 1–4 “n/5 steps”, State 5 “Complete”. Several strings have a trailing space (trimmed).
  • Dark State 5 track uses #E2EAEC (the Light colour). It is hidden under the full fill; built with the Dark track #484858.
  • #484858 is not in tokens.css (off-token in Figma).
  • Light State 0 frame is fixed at 153px, the rest hug; 153 = bar + gap + text, so built as hug.
  • No accessible name, error, paused or indeterminate state in Figma.
  • Contrast: Dark text 3.37 : 1; fill vs Light track 1.69 : 1, vs white 2.06 : 1.
  • Fill width animation (0.2s) is added in build — Figma has no motion.

Industry gaps — not added

  • Indeterminate variant for unknown wait times. Carbon · Fluent 2
  • Error state (red bar, helper text) and success icon. Carbon · Fluent 2
  • A label above the bar naming the process, required even if visually hidden. Carbon
  • Big size, 8px tall (V1’s 4px matches Carbon Small). Carbon
