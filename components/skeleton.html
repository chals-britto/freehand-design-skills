Usage

Where it appears in Figma

Inside List rows, standing in for a column’s text while the row loads (example frame “MacBook Air - 1” on the Skeleton page). The List Column molecule uses it.

Light or Dark

Two component versions with their own fills. Figma does not say which surface each is for.

Size

Pick the Size closest to the width of the text it replaces. Figma has no rule for other widths.

Accessibility

Hidden from screen readers

The bars carry no meaning. Put aria-hidden="true" on each skeleton.

Say that the area is loading

Set aria-busy="true" on the region being loaded and back to false when the content arrives, so screen readers announce once. Do not move keyboard focus when content replaces the skeleton.

Source: Fluent 2 Skeleton

Motion

The shimmer stops under prefers-reduced-motion: reduce; the bars stay as the Default fill.

Open issues

  • Size=120, Theme=Dark is 30px tall in Figma; the other 9 variants are 38px. Built at 38px.
  • Top-bar width is not a fixed ratio of the bottom bar (73%, 67%, 63%, 71%, 63%). Only the 5 Figma sizes exist; no rule for other widths.
  • The two bars use different corner radii in Figma (14 and 10). Both render as 5px on a 10px bar. Built as one value.
  • No skeleton colour roles in tokens.css: Light reuses --border-input-light, Dark reuses --dark-input-text. Dark shimmer #484858 is off-token.
  • Figma does not say which surface the Dark version sits on.
  • Contrast (accessibility pass): Light fill #E2EAEC on white is about 1.2 : 1, so the placeholder is faint. Decorative, so no WCAG minimum applies; kept as Figma.
  • Shimmer is rebuilt from the Figma prototype (smart animate between gradient fills) as cross-fading gradient layers. Close to the prototype, not frame-exact.
