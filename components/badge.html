Usage

From Figma

Indicator Ribbon: “Ribbon for listing card”. Nothing else is documented. The documentation block on the page still reads “Enter Description” and “Enter suggestion here”.

Properties

  • Callout: Notification Text
  • Badge: Show Label (Large), Count (default “+3”)
  • Ribbon: Show Checkbox (default off)

Accessibility

Static text

Nothing here takes focus. Dots and icons are decorative (aria-hidden); the text must carry the meaning.

Open for the accessibility pass

Below 4.5 : 1: Callout Error 3.48 · Badge Small Red 3.14 · Badge Large Red value 3.31 · Ribbon Error 3.66. Kept as Figma for now.

Open issues

  • The documentation block on the page is an empty template. There are no usage rules.
  • Callout Info uses the Status/Brown palette (reads as a warning). The variant property is still named “Property 1”.
  • Callout icon colours #A05A00, #760000, #1F7600, #1CCA00, #570000, #115700 are not in tokens.css.
  • Badge colour names don’t match: Small “Red” is Status/Orange-Dark #F94200; Small “Green” text is Status/Cyan-Dark #006265.
  • Badge Large Red value is raw #E25757 (no style). Its sample mixes weights (“+” and “more” regular, the amount bold).
  • Only 6 of 12 Badge combinations exist: no Small Blue, no Large or Red/Green Count.
  • Figma line heights are “auto”. The kit uses 17px (12 semibold) and 14px (12 bold). Label and Count use 0 tracking, where .type-10-semibold has 0.5px.
  • Ribbon set name has a typo (“Indicator Ribbbon”). The notch on the tail is rounded in Figma; the kit draws a close SVG curve.
  • Ribbon “Show Checkbox” uses the Checkbox component, which is not in the kit yet. A native 14px checkbox stands in.
  • Contrast below 4.5 : 1 on four variants (see Accessibility).
