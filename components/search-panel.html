Search Panel

A search card with two tabs. lane searches by lane type: pick a type, pick how to search it, type or pick a value, and Apply turns it into a tag so searches combine across types. vendor is a search field over a checkbox table of vendors. Figma has no written description; this is drawn from the 16 variants.

Try it

All behaviour is added — Figma has static frames only. Switch tabs; pick a Type and a sub-type; type to filter the value rows (↓ / ↑, Enter picks); Apply turns the value into a tag and moves to the next type; × removes a tag. On vendor, tick rows — picks show as tags in the field.

Usage

lane tab

The Type row lists lane types (lot/ lane, Source, destination, mode, movement type, Delivery type). lot/ lane, Source and destination show a sub-type row (lot · lane; code · port · city · state · zip · region · country) and take typed text. mode, movement type and Delivery type list their values instead. Apply turns the value into a tag (“Source : Hyderabad”) in place of the type chip. The tip line is Figma’s: “Search for a single value within a lane type, but combine searches across types”.

From the variants only — Figma has no usage text.

vendor tab

Search field over a one-column checkbox table (“vendor name”). Picks show in the field as Input Tags, first three and then “+ n”. In the vendor variants the lane tab is Disabled.

Built from

Kit Tab Group, Search Input, Toggle Tab (Single Selection with Description — the frame is literally a detached “Toggle Tab” with a “Description”), Input Tag, Multiselect Tag, menu table rows and header, Checkbox, Button + Button Group, icons. Built here: the secondary chip, labels on inactive chips, the tip and the frame.

Accessibility

Roles

The card is role="search". Tabs are the kit tablist / tab / tabpanel. The Type and sub-type rows are kit radiogroups (“Type” labels the first; the second is “Search by”). The field is a combobox controlling the value rows or vendor table (listbox / option, aria-activedescendant; vendor list is aria-multiselectable). Tag × buttons are named “Remove <text>”.

Keyboard

Tabs: ← / → / Home / End. Chip rows: arrows, selection follows focus. Field: ↓ / ↑ move the highlight, Enter picks it (or applies the typed value when nothing is highlighted); Backspace in an empty vendor field removes the last pick. Focus outlines (2px #0076DD) are added — not in Figma.

Contrast (for the a11y pass)

Active chip white on #0078DD 4.4 : 1 (fails 4.5). Tip #737373 on white 4.7 : 1. Default chip edge is shadow only. Secondary chip fill #F3F6FC on white 1.06 : 1. Type row rule #EEF2F4 1.1 : 1. Search icon #A3A3A3 on #F8F8F8 2.4 : 1. Disabled Clear #A3A3A3 2.5 : 1 (exempt). Field has no visible label: aria-label = placeholder.
