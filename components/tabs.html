Usage

Usage text

Figma has no usage text for this component. Used by the Search panel.

Behaviour

  • One tab is always selected; the first enabled tab by default.
  • Click selects. ← → move and select (wraps); Home / End jump to the ends.
  • Disabled tabs are skipped and ignore clicks.
  • No hover state in Figma.

Not the Toggle Tab

The Atoms Toggle Tab is a 2-option segmented control that switches a value in place (radiogroup). Tab Group has any number of text tabs with an underline, and each tab controls its own panel (tablist).

Accessibility

Roles

role="tablist" with an aria-label; role="tab" buttons with aria-selected and aria-controls; role="tabpanel" with aria-labelledby and tabindex="0". tabs.js fills in what is missing.

One tab stop

Roving tabindex: only the selected tab has tabindex="0". Arrow keys move inside the row. Disabled tabs use aria-disabled="true".

Focus ring

2px solid --pando-blue, offset 2px. Added in review — not in Figma.

Open issues

  • Dark, Background=No: the inactive tab instances have no underline and are 16 high instead of 25, so their labels sit 4.5px lower than the active one. Built top-aligned like the other variants, inactive underline left out as in the instances.
  • .Tab Dark variants are fixed at 77.3 high in the base set (stale sizing).
  • Missing states: no hover, no focus, no Dark Disabled. Focus added in review.
  • Disabled colour #A3A3A3 (--grey-medium) is not --text-disabled #A3A2A2.
  • Line-height: Figma auto (≈16); .type-12-semibold is 12/17, so a tab is 26 high instead of 25. 0.3px tracking and the 1.5px stroke have no tokens.
  • Contrast: Light bottom rule #EFEFEF on white 1.15:1 (WCAG 1.4.11 asks 3:1). Dark, Background=No has no fill — on white (as drawn in Figma) inactive 3.38:1 and active 2.06:1. Dark inactive on #24242F 4.54:1 (just passes). Light inactive on #F8F8F8 4.94:1.
  • The group hugs its tabs; whether the bottom rule should span the full container in product is not specified.
  • Same page also holds a different Toggle Tab set (2386:7366, numbered option pills) with .Individual Tab, .Toggle Base, .Option — not part of this molecule, not built.

Not adopted: Toggle Tab set 2386:7366 and its bases · loose Toggle Tab instances 3246:1120, 2533:9615 · loose groups 2386:7381, 2386:7384 · backdrop rectangle 2426:8065.

Industry gaps — not added

  • Hover and focus states — Carbon Tabs
  • Overflow: scroll with arrows (Carbon) or an overflow menu (Fluent 2, Ant)
  • Icons in tabs, icon-only tabs — Fluent 2 TabList
  • Vertical orientation — Fluent 2 TabList
  • Manual activation for slow-loading panels — Carbon Tabs
  • Sizes, closable / addable tabs, extra actions in the bar — Ant Tabs
