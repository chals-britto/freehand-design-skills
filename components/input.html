Usage

Overview (Figma)

Text Input and Dropdown Input.

Figma documentation blocks 3193:1918 and 3537:4513. Their “Uses” and “Placement & Convention” fields are still the template text, so no usage guidance is published yet.

Info icon review change

  • Place the 12px info icon top-right inside the field.
  • Hover or keyboard focus shows the tooltip above it; it hides on leave, blur or Esc.
  • Use it for short supporting detail, not for anything needed to fill the field.

From Figma 11396:3213 and the Tooltip component (Style=Text).

Messages added in review

  • One line under the field. Helper text stays visible while typing.
  • On error, the message replaces the helper and says what to fix.

Sources: Carbon · WCAG 3.3.1

Accessibility

Labels

Every field has a real <label for>. Required adds a visual “*” (hidden from screen readers) — also set required / aria-required on the control in product code.

Source: WCAG 3.3.2

Errors and helper

Error sets aria-invalid="true"; the message is linked with aria-describedby and announced with role="alert".

Focus added in review

Active keeps the Figma blue border; keyboard focus adds a 2px --pando-blue outline, 2px offset.

Source: WCAG 2.4.7

Tooltip

The info icon is a <button aria-label="More information">; the tooltip has role="tooltip" and is linked by aria-describedby. It shows on hover and focus and closes on Esc.

Source: WCAG 1.4.13

Dropdown

The trigger is a <button aria-haspopup="listbox" aria-expanded>; options are role="option" with aria-selected. ↑ ↓ move, Enter/Space pick, Esc closes.

Open issues

  • Contrast (a11y pass deferred, values kept): default border #E2EAEC on white 1.22 : 1, inline hover #B5C3CB 1.81 : 1, dark field #484858 on #393945 1.27 : 1 — all below 3 : 1. Error label #E25757 on #FFF8F9 3.5 : 1, dark error #E25757 on #FFEAEE 3.18 : 1, prefix #9C9C9C 2.75 : 1, disabled dropdown #9C9C9C on the disabled fill 2.59 : 1, dark dropdown error #D26568 on #393945 3.15 : 1 — below 4.5 : 1.
  • Off-token colours used as component tokens: #9C9C9C (prefix, disabled dropdown), #484858 (Dark/Input BG, and its 50% disabled), #737373 (formula placeholder; its style is named “Text/Light-#B4B4B4”), #404040 (formula argument colour), black 80% (tooltip).
  • Error state is colour-only in Figma (light): no message. The message line is added in review.
  • Disabled reads like enabled: disabled placeholder is the same #6C6C6C as enabled; disabled filled #545454 is darker than an enabled placeholder. Dark disabled text #F9FAFA is brighter than the enabled placeholder #E2EAEC.
  • Small (100): the LABEL row is 180 wide inside a 100-wide field (overflows in Figma). Built with the label clipped to the field.
  • Large (400) + Icon: Figma's input row is 180 wide, so text truncates at half width. Built full width.
  • Multi-Tag Input: Tags frame has 215 right padding inside a 190-wide frame. Built without it.
  • Tag Input + Icon (200, 4117:7050) shows no tags — identical to Default Filled + Icon. Rendered as Figma.
  • Table (Open) attaches a 400-wide Dropdown list to a 200-wide field. The Table list itself is a dropdown part and is shown as a placeholder here.
  • Dropdown No Label (Open): the list is placed at y 0, over the field. Built under the field.
  • Dropdown Error (288:492) and dark Text Input Disabled (175:180, 177:5) are detached from .Base Input; Inline uses a detached frame inside the instance.
  • Empty dropdown placeholder is italic; Input - Text placeholder is regular. Kept as Figma.
  • Active and Open share the same blue border; Default · Active · Large (3665:3477) also shows the list and a clear ×. Rendered as Figma.
  • Dropdown Condition uses the disabled grey fill (#E7E7E7 30%) and #EFEFEF border even when enabled, with a blue #0076DD value.
  • Dark dropdown has no field box while the dark text input has a #484858 box.
  • Text Area: dark only; no light theme and no Filled / Error / Disabled states. Its variant property is still named “Property 2”.
  • Line heights are Auto in Figma (≈16px for 12px text, 14px for 10px); built with .type-12-* (17px) and .type-10-regular (12px). Field height is fixed, so sizes still match. Label caps use 0 tracking in Figma (V1 caps classes use 0.5px).
  • Helper text colour (--text-light) and the 3px field-to-message gap are build choices — not in Figma for light inputs. Confirm.
  • Read-only has no Figma visual: it looks like Filled and keeps the default border on focus. Confirm a visual.
  • The added focus ring is --pando-blue on the dark surface too (~2.4 : 1). Needs a dark ring colour.
  • Figma documentation blocks: “Uses” and “Placement & Convention” are template text; Dropdown Select overview copies the Text Input overview.
  • Dropdown parts (.Dropdown Option, .Header, .Table Cell, .Custom Add, . Toggle, .Blinking cursor, Dropdown list, Dropdown Light, .Dropdown Dark) live on this page; only what the Open variants show is rendered.
