Usage

Uses

The text label updates based on information but they are not clickable or actionable. Keep the text as short as possible (2 words or less).

Placement & convention

Order of Status (In Workflows) in color is as follows:

Figma names “Yellow” as step 3; there is no Yellow variant — Brown is shown. See Open issues.

Accessibility

Text, not colour

The label always says the status; colour only supports it. Icons are aria-hidden. If an icon adds meaning (e.g. Sea), add visually-hidden text.

Not focusable

Status is read-only: a <span>, no role, not in the tab order.

Open for the accessibility pass

Light Orange 3.33 : 1 and Red 3.48 : 1 are below 4.5 : 1. Dark on the sidebar: Purple 3.18, Red 3.84, Blue 3.96 : 1. Dark on a white page fails for every colour.

Open issues

  • Doc order lists Yellow (step 3) but there is no Yellow variant; Brown appears to fill the slot.
  • Light Purple Horizontal (Default + Small): fills are raw hex, not linked to the Status/Purple styles (values match).
  • Widths are fixed (140 / 107). Long-label behaviour isn’t defined; built with single-line ellipsis.
  • Dark has only Horizontal Default — no Dark Vertical or Small.
  • Label ↔ icon strip: −1px in Light, 0 in Dark.
  • Line-height: Figma auto (16px) vs .type-12-semibold 17px — overridden to 16px.
  • Contrast below 4.5 : 1: Light Orange 3.33, Light Red 3.48; Dark (on --dark-bg) Purple 3.18, Red 3.84, Blue 3.96.
  • Icons are instance-swaps from 4 icon sets on the Icons page; only the 4 sample icons are embedded here.

Industry gaps — not added

  • Dismissible, selectable and operational types. Carbon Tag · Ant Design Tag
  • Truncate long labels and show the full text in a tooltip on hover/focus. Carbon Tag
  • Three sizes (V1 has two widths, one height). Carbon Tag
  • Filled / solid / outlined variants. Ant Design Tag
  • Sentence-case labels (V1 is uppercase); aria-label for icon-only badges. Fluent 2 Badge
