Usage

Uses

  • Tags are used to label, organize, or categorize objects.
  • Use tags when content is mapped to multiple categories, and the user needs a way to differentiate between them.
  • Tags can also be used as a method of filtering data, to show only items within that particular category.

Placement & convention

Display tags as a single category, dimension or property related to adjacent content.

Which tag (Figma descriptions)

  • Tag — Tags, text tag, Attachment tag, nimbus tag, cell tag.
  • Multiselect Tag — Show numbers, counts, units as tags.
  • Input Tag — Use for displaying filled input as tags in fields, search and comments.
  • Filter Tag — Filter Tags.
  • Pointed Tag — Pointed Tag.

Accessibility

Remove ×

The close × is a <button> with aria-label="Remove <tag text>", reachable with Tab and pressed with Enter or Space. Focus ring: 2px Pando blue. Added in review — not in Figma.

Colour is not the only signal

Every tag carries its meaning in text (“Rejected”, “Approved”). Keep it that way.

Open issues

  • Variant names do not always match the look: Type=Filled, Color=Brown, Rounded=Yes, Right Icon=True (Light and Dark) is drawn as an Outline tag; rendered as drawn.
  • Rounded · Blue (Light) uses the Sky Blue palette (#B5E4FF / #09375D), not Blue.
  • Medium · Dark fills are 10% tints not in tokens.css (#362F30, #37333A, #433F3A, #3B4545, #2F362F); Red and Green share #2F362F. Dark Grey / Neutral / Blue medium tags do not exist.
  • Rounded · Dark padding is fractional (2.16 / 4.32 / 1.62, gap 5.4) — looks like a scaled copy.
  • Square Small · Light text is Text/Dark for every colour except Red; Dark mode Brown uses the Light fill.
  • Tag/AI “Beta” uses Inter Semi Bold 8 — not Open Sans and not in the type scale. Dark Beta colours #FFE01B / #003D31 and the spark gradient stop #19A476 are off-token.
  • File tag text is pure #000000 (off-token).
  • Read Only Label boolean on Large tags: the label layer is hidden by default and was not rendered; Medium shows the same Label : Info pattern.
  • Line-height differences: Figma uses AUTO on most tag text (tokens: 10px → 12, 12px → 17); Filter Tag uses 11/16 vs .type-11-regular 11/15. Heights are fixed so the tags keep Figma’s size.
  • Text styles named “10px/Semibold/Normal” and “Regular 10” have no tracking, while .type-10-* classes add 0.5px — the component sets letter-spacing: 0.
  • No hover, focus, pressed or disabled states for any removable or filter tag.
  • Remove behaviour is not specified in Figma; the × is rendered but removing is left to the product.
