Calendar

An interactive calendar for date selection experiences. The calendar component provides a way to render dates for selection or presentation purposes.

Try it

Click the field (or press ↓ in it) to open the calendar. Arrow keys move by day / week, PageUp / PageDown by month (Shift: year), Enter picks, Esc cancels. Apply writes the value into the field.

Variants

All 11 published variants of Calendar (164:3009), drawn with Figma’s sample data (October / November 2025, 13 selected, range 13 Oct → 22 Nov). Grids are real months, so weekday positions follow the real 2025 calendar, not Figma’s sample layout.

Parts

Usage

From Figma (.documentation)

  • Select single date
  • Select Range of dates
  • Choose between date types for Filtering
  • Choose a single day
  • Choose from Day options

Placement & convention: “Placed below date input field or a date selector”.

Which variant

  • Month · Single — one date, with optional Date / Time fields (Show Time).
  • Month · Double — two months side by side; Range Selected = a start–end range.
  • Year — pick a year, 20 per page.
  • Day · Single — a day of the month (1–31 or Last Day of Month).
  • Day · Double — range with Next 3 Days / 7 Days / 1 Month.
  • Multi Date — date-type tabs above a range calendar (filters).

Opening from a field

  • pdsCalendar.attach(input, options) opens the panel under a kit input.
  • Apply writes DD-MM-YYYY (Figma’s format), or DD-MM-YYYY – DD-MM-YYYY for a range.
  • Cancel, Esc or a click outside leave the field unchanged.

Attach and keyboard added in review — Figma shows panels only.

Accessibility

Roles

Each month is a grid labelled with its month; days are gridcells with aria-selected and a button labelled “13 October 2025”. Today has aria-current="date". Disabled and outside days are aria-disabled. Multi Date tabs are a tablist. The attached panel is a dialog; the field gets aria-haspopup, aria-expanded, aria-controls.

Keyboard (added in review)

  • One tab stop per grid (roving tabindex).
  • ← → ↑ ↓ day / week (year: ±1 / ±4), Home / End week row.
  • PageUp / PageDown month, Shift for year (year view: 20 years).
  • Enter / Space picks, Esc cancels and returns focus to the field.
  • ← → switch Multi Date tabs.

For the accessibility pass

  • Focus ring 2px --pando-blue on days, carets, tabs, fields — added in review, not in Figma.
  • Outside days #CBD4D8 on white 1.5 : 1; disabled #A3A3A3 on #EFEFEF 2.1 : 1 (intentionally faint, but still below 4.5).
  • Range #313131 on #E9F1F5 passes; dark day #D5DAF4 on #24242F passes.
  • Field value #616161 on white 6.2 : 1 passes. Carets are 7.5 × 12 targets (below 24 × 24).

Open issues

  • Atom variant missing in kit: “Cell Input Field” (remote, Size=Small) — 34px label-less field, padding 9 / 10, 1px #E2EAEC inside, 12 SemiBold #616161 (dark: #484858, no stroke, white). input.css has no 34px field without a label, so it is built inside the calendar as .pds-calendar__field.
  • Day and Multi Date variants are drawn by hand (detached frames: 32px cells, gap 10, 30px rows, weekday 12 Regular +0.5), not from .Weekdays & Weeks. Built as a second “wide” grid. In those drawings the range band has no fill on Multi Date, leading days are white text, and Day · Double uses #0078DD (off-token) for the ends — built with --pando-blue and the Day · Double band (#E9F1F5, radius 20).
  • No today marker, hover, focus or pressed state on day cells in Figma. Today is only announced (aria-current); “Now” / “Today” buttons jump to it.
  • Selected year cell size was not read (assumed a 28px-high pill, padding 0 10, like the day dot).
  • Figma always draws 5 week rows; real months that need 6 rows get a 6th (panel grows by 28px).
  • Time field: Figma shows “10:00 AM”; the kit Timepicker it opens is 24-hour and writes “HH:MM”. “Now” fills the current time in the same 24-hour format. Confirm the time format.
  • Multi Date · With Time: “Select Time” + three time fields (10:00 AM, 12:00 PM, 3:30 PM) — their purpose is not described; built as editable fields returned with Apply.
  • Day · Double presets (Next 3 Days / 7 Days / 1 Month) are Cell Input Fields in Figma; built as buttons that set the range from today (added in review). Active preset gets the blue field border (added in review).
  • Dark theme exists for Month variants only; Year, Day and Multi Date have no dark design. Dark Apply keeps the Light primary button (as Figma).
  • Inconsistencies kept as Figma: Light · Double · Range uses Cancel at Normal size (others Small); Light · Double no-range is 524 wide with 10 gap (others 534 / 15); dark double panels use --shadow-2, light --shadow-4; dark single caret #EEF2F4 vs double white.
  • Off-token colours: #18283B (selected .Date Selector text), #616161 (field value), #484858 (dark header bar, divider, fields).
  • Line heights: Figma uses auto (16px) for 12px text; .type-12-* is 17px — overridden to 16px. Weekday 11 Regular auto (15) matches .type-11-regular.
  • Kit buttons render uppercase (RESET, NOW, APPLY) — Figma shows the same Bold 10 uppercase, so this matches here.
  • Range text format in the field (“DD-MM-YYYY – DD-MM-YYYY”) and all behaviour (keyboard, attach, Reset/Now/Today actions, tab memory per date type) are not in Figma.
  • Year view has a hidden Search Input in Figma (not built).
