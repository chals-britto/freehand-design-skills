AI Chat window

The full AI chat panel: header, conversation area and the prompt bar. Two themes in Figma — Light “Chat” and Dark “AI Chat” — each in three content variants (Prompt, Swappable, Conversation), plus the “Prompt” suggestion cards. Figma has no description text on these sets.

Try it

Type and press Enter (or click a suggestion card to fill the bar first). Your message appears as a user bubble, the loader shows, then a canned demo reply appears, outlined with a dashed line. No AI is connected. Header buttons only fire events — see the log.

Demo reply text is Figma’s sample “Input text here”.

Variants

Every published variant with the real classes: 3 Light windows, 3 Dark windows, 6 suggestion cards. Windows are 720 wide as in Figma (scroll sideways on small screens).

Usage

From Figma

No usage guidance in Figma. The two themes are separate sets with different headers (Light: More Actions · New Tab · Close; Dark: New · Close).

Built behaviour

  • Send adds a user bubble, then a Loading bubble, then a canned AI bubble (demo only).
  • The first message replaces the Prompt / Swappable content with the conversation.
  • Suggestion cards fill the bar; they do not send.
  • Header buttons fire pds-ai-chat-window:* events; no destinations in Figma.

Accessibility

  • Window is a <section> named by its title; the title is an <h2>. Messages sit in a role="log" with aria-live="polite".
  • Icon buttons are named: “More actions”, “Open in new tab”, “Close”. Suggestion cards are buttons in a list.
  • Focus 2px solid --pando-blue, offset 2 on header buttons and cards — added in review, not in Figma.
  • Contrast for the accessibility pass: Dark title #FFA600 on the header gradient 6.3–8.9:1 · Light card text #545454 on #F9FAFA 7.2:1 · Dark card white on #484858 50% 10.5–13:1 · Dark card hover white on #8A8A9E 3.4:1 · Light “Pi” label #008D5E on white 4.2:1 · Light time #6C6C6C on #EBF1FA–white 4.6–5.3:1 · Dark divider #484858 1.4–1.9:1 (decorative).

  2. Light uses the older .Bottom Bar, Dark uses Chat Bar — the two themes use different bar generations.
  3. Light Prompt overrides the composer Prompt: intro “Ask Pando AI about your <placeholder text here>” uppercase, left-aligned; cards 157 × 58, padding 5/10 (composer 56, 4/8). The second set named “Prompt” (3572:14750) is a different card: radius 4, 12/16, own Light/Dark colours — two suggestion styles exist.
  4. Close-Tag and “New” glyph colours in the Dark header were not readable (nested in remote instances); built white from the screenshot. “New” is the Light Action Button with white text; its hover on dark is the kit Dark Action hover — not in Figma.
  5. Off-token: #EBF1FA (window gradient + Light header), header shadow 0 1 9 10%, #FFA600, #484858 (divider, Dark card 50%).
  6. Line heights: Light bubble 12/auto → 16; Prompt card 12/16 (.type-12-regular is 12/17); heading 16/auto → 22; time tracking not read.
  7. Light “Pi” label icon is inlined from the Figma vectors (ring + sparkle, stroke #006265 → #19A476); no kit icon. Star fill not read.
  8. No states in Figma for: sending/disabled while the AI responds, errors, empty history, scroll, minimise, resize. Header buttons have no destinations.
  9. Dark Prompt: the Loader and prompts sit in a 90px-bottom-padded frame; exact vertical position approximated (centred).
  10. Light Prompt card “Icon” type is Dark only — no Light + Icon variant; Light cards have hidden Comment icon + caret layers.
