Range

The Figma Range page publishes three slider sets: Range (one handle, Dark/Light, Tight/Loose ticks), Slider (two handles, Pando blue fill) and Dual Range (two handles, light blue fill). All three are built here as published. The Figma Overview text is copied from Carbon, so it is listed under Open issues and not used here.

Try it

Drag a handle, click the track to make the nearest handle jump there, or Tab to a handle and use the arrow keys, Home and End. The keyboard keys and the focus ring are added in review — not in Figma.

Dual Range

Range set 3235:3847

Theme × Spacing = 4 variants, plus the Label and Scale booleans. “Spacing” really sets tick density: Tight = 21 ticks, Loose = 5. No filled track. Dark variants are shown on --dark-darker for display only; the backdrop is not part of the component.

Slider set 8568:2053

Level = 0 to 1 / 0 to 1.5 / 1 to 1.5. Handle positions are copied from Figma; the Level names do not match them (see Open issues).

Dual Range set 8570:1364

Level = 0 to 2 / 0 to 16 / - to 4 / 2 to 4, plus the Show Scale Count boolean. “- to 4” draws the same as 0 to 4 in Figma.

Usage

Only Figma text that is not copied from another system. Copied and placeholder text is listed under Open issues.

When to use

  • Sliders provide a visual indication of adjustable content, where the user can increase or decrease the value by moving the handle along a horizontal track.
  • Use when selecting a single value or range of number values.
  • Use sliders when there is a need to show a selection of a single value or range of values.

When not to use

  • Do not use for extremely large ranges, for example, 1-Max.
  • Do not use ranges that are too small, for example, 1-2.
  • Do not use complex inputted values that are not numbers.

Behaviour

Sliders can be manipulated by moving the thumb along the track, or by selecting a spot along the track that the thumb will jump to.

Placement & convention

The slider label should indicate what value the slider is changing. Range values are used to describe the range in numbers.

Do & don’t as in Figma · no captions

Accessibility

Each handle is a slider

range.js gives every handle role="slider", tabindex="0", aria-valuenow/min/max and a label (the field label, or “Minimum” / “Maximum” on two-handle sets). For two handles, each one’s min/max is the other handle’s value, so they cannot cross.

Source: WCAG 2.2 · 4.1.2

Keys and focus added in review — not in Figma

←/↓ one step down, →/↑ one step up, Home/End to min/max. Focus ring 2px --pando-blue, offset 2. Click-to-jump (from the Figma Behaviour text) is the single-pointer alternative to dragging.

Source: WCAG 2.2 · 2.5.7

Open for the accessibility pass

14px thumb is under the 24×24 target. Light track, Dual Range fill and dark track are under 3:1. Kept as Figma for now; ratios under Open issues.

Sources: 2.5.8 · 1.4.11

Open issues

  1. Three sets doing the same job — pick one. Range (one handle, no fill), Slider (two handles, --pando-blue fill) and Dual Range (two handles, --highlight-blue-light fill) all select a value on a dotted track. They differ in fill colour, track radius (9 / 1000 / 8), dot colour (#B5C3CB vs #F8F8F8), scale style and spacing.
  2. Overview copied from Carbon. It describes a “default and range” slider with number inputs; V1 has no number input and the Range set has no two-handle variant. Not used on this page.
  3. When to use: the 4th bullet (“Use when needing to expose a variety of options or to limit the number of options quickly.”) matches Carbon’s wording; left out of Usage. Bullets 2 and 3 say the same thing.
  4. Behaviour: “All interactions are optimized for mouse, keyboard, and touch.” is Carbon wording, and no keyboard rules or focus state exist in Figma. Left out of Usage; the keys in Try it are added in review.
  5. Placeholder text: the old .documentation block’s “Uses:” field still says “Enter suggestion here”.
  6. Do / Don’t have no captions. The Don’t (scale ending in “MAX”) only makes sense next to the “1-Max” bullet.
  7. No states in any set: no hover, focus, pressed, disabled or error. Range “Type” has one option (Stepper); default Theme is Dark.
  8. Range has no filled track. The value shows only by handle position and the highlighted scale label — and Dark Tight has no highlighted label at all.
  9. Thumb: 14px (light) is under the 24×24 target; light 14 vs dark 20 with no reason; built from Navigation/Collapse-Expand parts, not a thumb component. Dark carets use the Forest Green gradient; the light thumb border uses dark-theme --dark-input-text.
  10. Light Loose track is 191×9 (others 200×8) and has 17 hidden dot layers; its end labels don’t line up with the track ends.
  11. Slider: scale colour “Gray Text” #667085 is not a V1 token; the 16-dot variant labels 0–14 (12–14 sit outside the scale frame); the other two levels have no scale; Level names (0 to 1.5…) match no shown number; widths 374 vs 324; set name has a trailing space.
  12. Dual Range: “- to 4” renders the same as 0 to 4; three hidden “16” labels in #667085 in every variant.
  13. Contrast (non-text, < 3:1): light track vs white 1.22:1 · Dual Range fill vs track 1.32:1, vs white 1.61:1 · dark track vs #24242F 1.93:1 · tick dot vs light track 1.48:1. Thumb border vs white 3.38:1, Pando blue fill vs track 3.71:1.
  14. Type: Label is 12/auto (built as .type-12-regular 12/17). Range scale is 10/auto, tracking 0 (built with --type-10-regular 10/12, tracking 0); selected uses --type-10-semibold. Slider/Dual scale use 10/12 +0.5 for the same role.
  15. Thumb positions map to the scale label centres; within ~2px of Figma. Dark Loose and Dark Tight place the track differently inside the component (x 5 vs 0).
  16. Dark variants rely on a loose dark rectangle to be readable on canvas (white label on a transparent component).
