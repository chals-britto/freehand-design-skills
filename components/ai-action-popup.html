Try it

Pick an option, or type in “Something else in mind” (that clears the option). Confirm or Enter sends the answer, then the popup shows the Responding text for a moment. Hover an option for its Hover state. The prompt bar is the live kit composer.

Usage

Composition

  • Popup = card + kit Radio, kit Input - Text, kit Button Group (Skip, Confirm) + disclaimer.
  • .Input = the kit composer bar with a Prompt chip in front of +, and an optional Skipped message or Tagged context above it.
  • The Slideout Chat composes these classes.

Two popup types

  • Default: confirm a set of field changes (“from → to”).
  • Option: the AI offers interpretations; the person picks one or writes their own.

Text from Figma

Figma has no usage notes for these components. Nothing else is added here.

Accessibility

Popup

A <section> named by its heading. Options are a <fieldset> of native radios, so arrow keys move the choice. Enter in the text field confirms. Focus rings added in review — not in Figma.

Prompt bar

From the composer: <textarea> named “Ask Freehand”, Add and Send buttons. The chip, the Skipped link and the Tagged × (“Remove context”) are buttons.

Responding

role="status" so “Processing” is announced once; the dots are hidden from screen readers. Reduced motion holds frame 1 and stops the spinner.

Open issues

  • Motion decision needed: .Responding_Text animation is 4 frames chained with After delay 1–10 ms + Smart animate 300 ms ease-out. Built as a 1.2 s CSS loop; reduced motion holds frame 1. Confirm speed, and whether it should loop at all.
  • The spinner in Responding is a 32 px animated GIF (blue ramp, darkest #047ADC) scaled to 12. Rebuilt with the kit Button spinner vector in --pando-blue so reduced motion can stop it.
  • Cursor/Typing is a 24 px GIF used as a mask with a #295EFF colour layer. Drawn as a CSS caret (1.5 × 13, blinking); only shown on the static Hover variant — a live field shows the real caret.
  • Prompt chip (Prompt · Theme=Light, State=Default, Type=Simple, set 3572:14750) is not in the kit yet (ai-chat-window, Batch 3). Built inside this component: atom variant missing in kit. Its Hover and Dark variants are not built here.
  • Instance overrides: Radio Selected ring/dot #FE6505 (kit #0076DD); Confirm fill and Skip label are a #041F04 → #343440 gradient (kit Primary #0076DD; Skip uses the Theme=Studio button, excluded from the kit, so the kit Secondary is used with the label override).
  • .Option master uses Regular 12 and no radio; every popup instance shows the Radio and SemiBold 12. Selected row (gradient + 0.1px orange stroke) is an override on the first instance, not a published state.
  • 0.1px strokes (Summary, selected option) are drawn as a 0.1px inset shadow — practically invisible, as in Figma.
  • Off-token colours: #FFF7ED, #1E2939, #737373, #DCDCDC, #295EFF, shadow 0 0 42 −12 16%, gradient #041F04 → #343440 (both ends are tokens).
  • Type not in tokens: SemiBold 16/auto (heading), Regular 9.5/12 (disclaimer), SemiBold 13/22 (summary values). 12/auto built at 16 (tokens 12/17); 10/12 without the 0.5px tracking.
  • Hidden in Figma, not built: Close-Tag in the popup header, the “Slot” under the body, the Divider above the actions, the bar’s divider, the right-hand Add and the “stop_responce” button.
  • No Figma behaviour for Skip, Confirm, the chip, the Skipped link or the Tagged ×; the events here are added in review. No disabled / loading state on Confirm.
  • Contrast: placeholder #737373 on white 4.7:1 (passes); Summary “from” #8A8A9E 3.4:1; Option hover text #FE6505 on white 3.0:1; Responding frames 2–3 grey text ≈ 1.6–2.5:1; disclaimer 9.5px #545454 7.5:1 but below 10px. Kept as Figma.

Industry gaps — not added

  • Suggested prompts can be disabled, carry a description line, and nest into sub-lists. None of these exist here. Ant Design X Prompts
  • Inline loading pairs the indicator with short status text and temporarily disables related actions while it runs. Here Skip/Confirm have no disabled state during Responding. Carbon Loading
