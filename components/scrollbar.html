The thin custom scrollbar for scrolling panels and menus. One class, .pds-scroll, in a Light and a Dark theme.

Usage

Where it goes

Add .pds-scroll to the element that scrolls — panels, lists, dropdown menus. Add .pds-scroll--dark on the dark sidebar surfaces.

In Figma

The Figma example places the handle 30px from the top with 10px spacing. That is only the picture; in the browser the handle’s position and length follow the content.

Accessibility

Still a native scrollbar

Keyboard, wheel and touch scrolling are unchanged. Make a scrolling region with content reachable by Tab (tabindex="0") and give it a name.

Open for the accessibility pass

Handle vs track: Light 1.16 : 1, Dark 1.27 : 1 — well below 3 : 1. The 6px bar is a small mouse target. Kept as Figma for now.

Source: WCAG 2.2 · 1.4.11 Non-text contrast

Open issues

  • Dark handle #484858 (Figma style “Dark/Input BG”) is not in tokens.css — kept as a component token.
  • Figma style name says “Dark/Dark-Bg-#393944”, the fill is #393945.
  • Handle-to-track contrast 1.16–1.27 : 1 (below 3 : 1).
  • No hover, active or dragging state, and no horizontal bar in Figma. Horizontal uses the same values.
  • Firefox can’t draw 6px or the 8px radius; it shows the browser’s thin bar (≈8px) in the same colours.
