Usage

When to use

  • Form — Can be used in tiles, data tables, modals, side panels, and in forms on full pages.
  • Settings — Used to change from one setting to another in a menu, page, or component. It can often act as a filtering mechanism.

When not to use

  • If a user can select from multiple options, use checkboxes instead of radio buttons. Radio buttons allow the user to select only one item in a set whereas checkboxes allow the user to select multiple items.
  • If there are two options showing an on/off setting, consider using Switch.
  • For lists with more than ten options, consider using a Select.
  • When there are only two or three options with short labels, consider using a Button Select.

Placement & convention

  • Always provide a label for a radio button.
  • Present the options in a logical order for the best context.

Behaviour

The radio button input allows for two states: unselected and selected. The default view of a radio button is having no radio button preselected. Only one radio button should be selected at a time. When a user chooses a new item, the previous choice is automatically deselected. If the user has already selected an item but wants to deselect it, consider adding alternatives such as an “other” or “none” option.

Keyboard added in review

  • Tab moves into the group, onto the selected option (or the first, if none is selected).
  • Arrow keys move to the next or previous option and select it.
  • Space selects the focused option.
  • Tab again leaves the group.

Accessibility

Native radios

Each option is an <input type="radio"> inside its <label>, so the label is clickable. Options in one set share a name; the browser handles arrow keys and Space.

Group and error

Wrap a set in <fieldset> with a <legend>. In error, link the message with aria-describedby and set aria-invalid="true". With Show Label off, give the input an aria-label.

Open for the accessibility pass

Ring #A3A3A3 on white is 2.52 : 1 (below 3 : 1). The control is 14px in a 16px row (below 24 × 24 unless the label counts). Kept as Figma for now.
