File Upload

A single row that shows whether a file has been uploaded, with the actions to add, upload or download it. Built from the kit Button, Label Readonly Text, Empty State (No File Uploaded - Small), Tag, Icons and Progress Indicator.

Status: Built from Figma, not yet reviewedFigma component 2466:10340 ↗Files: file-upload.css · file-upload.js

Try it

Click Add Files or drop files on the row. Nothing leaves your browser. Each file shows the kit Progress Indicator stepping through its Figma text; Upload turns on when every file reads “Complete” and turns the files into Verified rows. The chosen-file list, the × and the drop outline are added in build — Figma has none of them.

Events appear here.

Variants

Theme × Type = 4 published variants. Colours, text and sample data exactly as in Figma. Light rows sit on the Figma canvas grey only to show their white fill; Dark is shown on --dark-bg #393945 (the Figma variant has no fill and sits on the canvas).

Usage

Types

  • Not Uploaded — empty art, “No File Uploaded”, Add Files + Upload (Upload disabled). Dark shows only Upload.
  • Uploaded — file icon, file name, Download.
  • Verified — file icon, underlined file name, green check, and “Total entries : 50”.

Accepted types and size

Figma shows no accepted file types, size limit or helper text. None is shown here; the accept option only filters the picker and dropped files.

Figma has no usage text

The page has no description or guidance for this component. Sample data (“Lanes Sample Format”, “Lanes-Mar-22”, 50) is Figma’s own.

Accessibility

Keyboard

Add Files and Upload are real buttons; the file picker opens on Enter or Space and focus returns to the button that opened it. Each chosen file has a named × button (“Remove Lanes.xlsx”); after removing, focus moves to the next ×, else to Add Files.

Announcements

A polite live region says “2 files added”, “All files ready”, “Lanes.xlsx removed”, “2 files uploaded”. Each progress bar is named by its file name. Drag-and-drop is an extra path only — browsing does the same job.

Open for the accessibility pass

Dark “No File Uploaded” #8A8A9E: 3.37 : 1 on #393945. “Add Files” / “Download” #0076DD on #EEF2F4: 4.02 : 1. Green check #1FCD93 on white: 2.06 : 1 (a hidden “Verified” text carries the meaning). Kept as Figma.

Open issues

  • Figma has no accepted-types, size-limit, helper or error text, no drop zone, no in-progress state and no remove control. The chosen-file list, × (kit file tag), drop outline and simulated progress are added in build.
  • Dark exists only as Not Uploaded; there is no Dark Uploaded or Verified. The Dark Upload button is a Light Primary instance with a #343440 fill override — atom variant missing in kit (built as a component override).
  • Dark Not Uploaded has only Upload (no Add Files); here Upload opens the picker when nothing is chosen.
  • Off-token colours: empty text #616161 (its style is named “Text/Medium-#737373”), file name #404040 (style “Text/Dark-#404040”; tokens.css Text/Dark is #313131, the kit Label Readonly Text default).
  • Line heights: empty text is 12 / auto (built with .type-12-semibold 12/17); file name 12/16 vs .type-12-regular 12/17.
  • Verified “Total entries : 50” needs data the browser does not have — it is not shown for files chosen in Try it.
  • Hidden layers in Figma: a “Last Uploaded: 10 June 2021” line (8px), two hidden buttons and a second readonly line in Verified; an old hidden “no-file-uploaded” image in Dark. Not built.
  • Download does nothing (no file behind the sample). Uploaded has no remove or replace action.
  • Contrast below 4.5 : 1 — see Accessibility.
