Usage

Search Section

Advanced search over several fields at once. Booleans 1st Row, 2nd Row, 3rd Row show up to nine fields. In Figma row 1 uses Search Tag fields (“Name” chip); rows 2 and 3 use Default fields.

From the component only — Figma has no usage text.

Search chat

Searches chats and artifacts. Chips All / Chats / Artifacts narrow the list; each row shows a type icon (Comment = chat, Details = artifact — assumed from the icons), a title and a time. The highlighted row shows “↵ Enter” in place of its time.

Built from

Fields are kit pdsInput.build() (input.css/js). Buttons are kit .pds-button in a .pds-button-group. The chat field is kit .pds-search-input. Icons from components/icons/. Chips and .Search_Menu rows have no kit atom and are built here.

Accessibility

Roles

Search Section is a role="search" region; each field keeps its kit label. Search chat: the field is a combobox controlling the listbox of rows (role="option"), with aria-activedescendant. Chips are toggle buttons (aria-pressed) in a labelled group. × is a button “Close search”.

Keyboard

Tab reaches every field, chip and button. In the chat field ↓ / ↑ move the highlight and Enter opens the row. Focus outlines (2px #0076DD) are added — not in Figma.

Open issues

  • Atom variant missing in kit: the All / Chats / Artifacts chips (20 high, padding 3/6, radius 14, #F9FAFA + shadow, selected #0076DD). Toggle Tab “Single Selection” pills are 24 high with a #B5C3CB border, so they do not match. Built inside this component.
  • Atom variant missing in kit: the .Search_Menu row (36 high, 14 icon, title + time). Dropdown Option rows are 56 high with an avatar; built here.
  • Behaviour is not in Figma. Built: Clear All empties the fields; Search fires an event; chat typing filters, chips filter by type, ↑/↓/Enter, CLEAR enabled once there is text (Figma shows it Disabled only), × fires a close event.
  • Chip → row type is assumed from the icons (Comment = chat, Details = artifact). Figma does not say.
  • “↵ Enter” hint: only the Search chat instance shows it on the Hover row; the .Search_Menu Hover variant itself shows the time “12:52:00”. Built as: highlighted row in Search chat shows the hint.
  • Field tools overlay (CLEAR · line · ×) is an absolute frame on top of the Search Input, not part of it; the Search Input has no slot for it. Typed text gets 64px right padding so it does not run under it — added.
  • Off-token colours: #404040 (row title + meta), #18283B (chip text). Chip shadow is 0 1 3 10%; nearest token --shadow-1 is 0 2 3 10%.
  • Line heights: row title 12 SemiBold line Auto (16) vs 17 in .type-12-semibold (set 16); chip text 10 Regular line Auto (14) tracking 0 vs .type-10-regular 10/12 +0.5 (chip font is a component token).
  • Search Section field grid: 9 fields with no gap, so 1px inside borders meet as 2px lines. Row 1 Search Tag fields also carry Show Tag 1 / 2 = on in Figma, but no tags show (Search Tag type shows only the “Name” chip).
  • Search Section buttons: the Button Group instance (Type=Buttons) is overridden to Text Only Small + Primary Small; the kit group default is Secondary + Primary Normal. The kit group’s 30px min-height is reset so the row hugs 24 as in Figma.
  • Row titles are truncated by hand in Figma (“…by carrier f...”); built with CSS ellipsis and Figma’s text as-is.
  • No empty / no-results, loading or error state for either panel. No Dark theme.
  • Indicator icons are drawn #313131 here (kit default #234357).
