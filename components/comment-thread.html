Usage

Which part

  • .Comment — the comment text. With Type = .Tag + Comment, an Input Tag starts the text.
  • Chat Comment — author, time and the comment. An attachment tag can be shown below.
  • Comments — chat bubbles. Shipper on the left with name and tag; User on the right.
  • Swapable = yes — the bubble holds other content below the text.

Content

  • Time and message text are component properties in Figma (“10:39 AM”, “Input text here”).
  • The slot shows Figma’s placeholder: “Swap this component out with another.” Replace it with the real content.

Reused by

.pds-comment is also used inside the Chat Input Box molecule.

Accessibility

Who wrote it

The Comment Avatar and .User Tag show only a letter. Give them role="img" and an aria-label (“Transporter”, “Shipper”).

Time

Use <time datetime="…"> for the time so it can be read as a date.

A list of comments

Put several comments in a list (<ul> / <li>) so screen readers announce the count.

Open issues

  • Line heights: .Comment text is 12/18 and bubble/slot text 12/16 in Figma; built with .type-12-regular (12/17).
  • Off-token colours: .Comment text #404040, bubble fill #484858, slot body text #000000.
  • Inline Input Tag: Figma uses Remove = Yes (padding 4/8) with the × hidden. The kit only uses 4/8 when the × is present, so .pds-comment__tag sets the padding. Tag text is #404040 in this instance; the kit tag uses --text-dark #313131 (kept).
  • Type = .Tag + Comment is two fixed lines in Figma. Built as flowing text with the tag inline, so long text wraps naturally; the first line is 24px tall because of the tag.
  • Attachment tag: instance has Removable = Yes but Right Icon = False, so no × is drawn. Left icon content could not be read (hidden instance); the kit’s PDF file icon is used. Label is Figma’s “Tag Text”.
  • Comments has a “Toggle Tab” boolean that is not bound to any layer. Not built.
  • Comments exists only in dark colours, and .User Tag is filled with --dark-bg, so it disappears on a --dark-bg surface. Surface not stated in Figma.
  • .User Tag is a second dark Comment Avatar: solid --dark-bg fill, while the avatar atom’s dark variant uses #484858 at 50%. Both kept.
  • Message name in Comments is SemiBold 10 with no tracking; Chat Comment name is Regular 10 with 0.5px tracking. Both kept.
  • Slot placeholder icon is the kit refresh-line (20px, #234357, icons/refresh-line.svg).
  • The page’s .documentation card describes Chat Input Box, not Comments. No behaviour or usage text exists for these sets.
  • Contrast (accessibility pass): bubble time #8A8A9E on #484858 is about 2.6 : 1; Light chat time #6C6C6C on white is 5.3 : 1; Dark chat time #8A8A9E on #393945 is about 3.4 : 1.
