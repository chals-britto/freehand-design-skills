Usage

Types

  • Selection: picking the row selects it; the avatar turns into a blue check.
  • Viewable: a row that is already in a list; hover shows a delete icon.

From the variant names only — Figma has no usage text.

Where it is used

Search Input (2419:10052) and .Search Dropdown (2464:8997), both on the 🟡 Search page of the Molecules file.

Accessibility

Roles

Use as role="option" inside a role="listbox", with aria-selected. The avatar is decorative (aria-hidden). The delete icon is a real <button> with an accessible name.

Keyboard

The highlighted option (.is-active, from aria-activedescendant) uses the Hover look. Delete shows on hover, keyboard highlight or focus inside the row. Focus outlines are added — not in Figma.

Contrast (for the a11y pass)

Title #404040 on white 10.4 : 1, on #EEF2F4 9.2 : 1. Secondary #737373 on white 4.7 : 1, on #EEF2F4 4.21 : 1 (below 4.5). Hover fill vs white 1.13 : 1. Selected is shown only by the avatar change.

Open issues

  • How this relates to menu and dropdown. Nothing here is reused from menu.css: no variant matches an existing option part. Closest is menu .Dropdown Option · Multi-info (200 wide, 52 high, no avatar, title #313131, second line 10 Regular, hover #E9F1F5). The Atoms dropdown.css two-line panel row (loose frame 3240:4042) is nearest of all — 56 high, padding 10, 30px icon circle, 12 SemiBold #404040 title — but its secondary line is 10 Regular with a 6px gap, the icon is a cyan depot circle (#D7F3F6), and selected is a #F8F8F8 fill + right check. So three “option with icon + two lines” patterns now exist (menu Multi-info, dropdown two-line row, this). This one stays a separate molecule for Search; decide later whether the dropdown two-line row should become this.
  • Hover colour differs from the menu atom: #EEF2F4 here vs #E9F1F5 in menu.css.
  • Avatar glyph colour: Figma’s remote Icon Avatar (2541:10713) draws Depot in #2D0645; the kit avatar draws glyphs #234357. Kit avatar kept. The Selected avatar in Figma is a Purple avatar with a #0076DD fill override and Indicator Icon/Check 14 — matches kit .pds-avatar--selected.
  • Selection · Selected has no row fill and no text change; selection relies on the avatar only. It also carries a hidden second check layer (not built).
  • Viewable · Hover: the Delete icon is a 14px icon scaled to 12, #0D204A. What Delete does is not in Figma (no confirmation, no event spec).
  • Off-token: #404040 (title), #737373 (secondary).
  • Line heights: title Auto (≈16) and secondary 16 vs 17 in .type-12-*; set to 16px in the component so the row stays 56.
  • Fixed 300px width in Figma; long text truncates with an ellipsis (no Figma rule). No disabled state.
