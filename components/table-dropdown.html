Table Dropdown

The borderless dropdown that sits inside a table cell: a placeholder or value with an arrow, and a plain list 10px below it. Single select, checkbox multi select, or multi select with a tick.

Usage

Types

  • None: pick one value; the list closes.
  • Checkbox: pick several; each row has a checkbox; the list stays open.
  • Multi-Selected: pick several; picked rows get a tick on the right.

From the Figma variant names. Figma has no usage text.

Sizes

  • Small hugs its text.
  • Large fills the cell; filled multi selections show as tags.

Accessibility

Combobox + listbox

The field is role="combobox" and keeps focus; the list is a listbox with options marked aria-selected, and aria-activedescendant follows the highlight. Keyboard comes from menu.js.

Focus ring

2px --pando-blue outline on the field. Added in review — not in Figma.

Open for the accessibility pass

Hover/keyboard highlight #FAFAFA on white is 1.04 : 1 — almost invisible. Tag × buttons are not in the Tab order (deselect from the list).

  • No max height or scroll — long lists grow.
  • Input Tag text is #404040 in these instances; kit Input Tag uses #313131. Kit used.
  • Line height: Figma Auto (≈16) vs 17 in .type-12-*.
  • Hover contrast #FAFAFA on white 1.04 : 1.
  • The rows differ from the kit menu (36 high, SemiBold, hover #E9F1F5); a third list style.
