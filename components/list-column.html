Usage

Figma has no usage text for these sets. What follows describes the components as built.

Pick a type per column

  • Text — a value with a second line under it.
  • Text + Tag / Tag — a value with a count of more values (“+ 2”).
  • Status — the #Status atom, sized to the column.
  • Skeleton — while the row loads.
  • Route — origin, optional transit (“VIA”) and destination.
  • Swappable — any other content.

Width

Columns have a fixed width per Size (80 / 120 / 180 / 220). Text longer than the column is cut with an ellipsis (build choice — see Open issues).

List-Data and .Route

List-Data is a white cell with one or two lines and an optional checkbox for row selection. .Route is the route block used on its own: Single shows the “VIA” transit; Multi shows count tags and no transit.

Accessibility

Checkbox needs a name

List-Data has no visible label next to the box. Give the native input an aria-label (e.g. “Select row”) or point aria-labelledby at the cell text.

Skeleton

Keep aria-hidden="true" on the skeleton and set aria-busy="true" on the list while it loads (see Skeleton).

Route arrows

Arrows are decorative SVGs with aria-hidden. The order Origin → Transit → Destination is carried only by reading order and the “VIA” text.

Truncated text

Text cut with an ellipsis is still in the DOM, so screen readers read it all. Sighted users cannot see the rest — no tooltip in Figma.

Contrast (for the accessibility pass)

Main #313131 and Additional #545454 on white pass. Arrows #B5C3CB on white are 1.8 : 1 (decorative). “VIA” #005399 at 8px is about 7.8 : 1 but very small. Count-tag border #E2EAEC is 1.2 : 1.

Open issues

  • Text overflow is not defined for Type = Text, Text + Tag or List-Data (text hugs and would spill out of the fixed width). Built with an ellipsis, as Figma does inside Route (truncate ending).
  • Line heights: 12px text is Auto (16px box) in Figma; tokens use 17px. Built with 16px so the heights match (37 for Text). “VIA” is 8px SemiBold, Auto — no .type-8-semibold token; built as --type-8-regular + weight 600.
  • Status column is 130 wide; the kit Status default is 140. Built at 100% of the column. Size=Small keeps the kit’s 107px status inside a 130 column. Status label is uppercase without tracking in both.
  • Count tag text is #404040 in Figma (off-token); the kit Multiselect Tag uses --color-text-primary #313131. Kit kept. Input Tag text is also #404040 in Figma.
  • Route Size=Via and .Route Single are the same layout with different alignment (top vs centred) and connector bottom padding (5 vs 10). Built as one route with --route-center.
  • .Route has a text property “Via2” (default “Columbo”) and a boolean “Via”. The visible sample says “Transit Place”, so the text property’s target is unclear. Built: Via on = connector + transit place.
  • Hidden layers not built: second Input Tag in Type = Tag, Additional Text in Text + Tag, the “Pin” + dashed line in every route arrow, and the hidden transit in .Route Multi.
  • .Route Multi is a fixed 42px high in Figma (content is 33); built hugging, centred.
  • Size=Xtra Large Tag hugs (220) while the other Tag sizes are fixed. Size names are reused with different meanings (Route uses “Via” as a Size).
  • Swappable placeholder body text is #000000 (off-token). Placeholder icon is the kit refresh-line (20px, icons/refresh-line.svg).
  • No dark theme, no hover / selected row states, no empty-value state in any of the three sets.
