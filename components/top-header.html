Usage

What the variants are for

Figma: “Top Header denoting Shipper/Vendor/TransporterConsignee Portal.” The Type names the portal; the logo colour changes with it (orange for Shipper, amber for Transporter, cyan for Consignee).

Content

  • Client Name (Figma sample “Global Industries”, “Global Transporters”, “Global Consignee”) - Module Name.
  • Optional on the right (Freehand only): header icons, Support, and the AI Copilot button (Shipper) or a Button Group (Gradiant).

Where it sits

Full width at the top of the page. Toasts appear directly under it (see Toast, --header-height: 50px for this header).

Accessibility

Landmark

Use <header class="pds-top-header"> as the page banner. The client and module name go in one element so they are read together.

Icon buttons need names

Each header icon is a <button> with an aria-label (“Global search”, “Notifications”, “New features”). Figma has no labels; these come from the icon names.

Focus

2px --pando-blue outline, offset 2px — added in review, not in Figma. On #153F69 this ring is low-contrast; to check in the accessibility pass.

Open issues

  • Every variant, including Brand=Pando, uses the Freehand logo (“Header-Logo/Apps · Property 1=Freehand, Variant=Logo”), only recoloured. No Pando logo appears in this set.
  • Brand=Pando variants have no Right frame — the Show Icons / Support / AI Copilot booleans do nothing there.
  • Show AI Copilot Button exists only on Shipper; Gradiant has a hidden Button Group instead (and no AI Copilot slot). The boolean is on the set but has no layer to drive in Gradiant.
  • Type=Gradiant gradient (#153F69 → #005399, left → right) has no Figma style; --color-header-bg covers the solid variants only.
  • Divider #9CB3BF @ 50% is off-token.
  • Client name is Open Sans SemiBold 16 with auto line-height — the kit has no .type-16-semibold; built as 600 16/22. Support text is SemiBold 12 auto (kit 12/17).
  • Global Search uses the Active icon, Notification and New Features the Inactive ones. No hover/active states for the header icons are in this set.
  • Active Global Search icon draws #234357 on #153F69 — ≈ 1.0 : 1 for its dark parts. Inactive icons #CBD4D8 on #153F69 ≈ 7.2 : 1 (pass).
  • Support #006265 on #F8F8F8 ≈ 6.7 : 1 (pass). Divider at 50% is decorative.
  • No user avatar / profile, app switcher or skip link in Figma.
