Button Group

A row of buttons placed together, right-aligned. Every button inside is the kit Button atom; this component only lays them out.

Try it

The Figma properties. The three booleans only exist on Type = Buttons and all default to off.

Variants

Type = Buttons with each boolean, and Type = Action Buttons. Light theme, Normal size only (as in Figma).

Usage

Order

Primary is the last button, on the right. Optional buttons sit to its left in fixed slots. Hidden slots take no space.

Used by

Chat Input Box, Subheader, Top Header, Filter Light/Dark, Search Section, List “Options in Right”.

Guidance

Figma has no usage text for this component. None added.

Accessibility

Real buttons

Every item is a kit <button>, so focus ring and keyboard come from the Button atom. DOM order matches the visual order, so Tab moves left to right.

Name the group

When the buttons act on one object, add role="group" and an aria-label to the container. Guidance, not in Figma.

Contrast

As the Button atom. Action blue #376F99 on white passes 4.5 : 1.

Open issues

  1. Boolean names don’t match what they do: “Show All Buttons” shows one Dropdown in slot 1, not all buttons. “Show Button 4” is slot 2, “Show Button 3” is slot 3.
  2. No limit on the number of buttons: up to 5, with two Secondary and two Dropdown side by side.
  3. Type = Action Buttons is a fixed 5 buttons with no booleans; the count can’t be changed in Figma.
  4. Gap 20px is not on the spacing scale (component token --button-group-gap).
  5. Light theme and Normal size only. The Button atom has Dark and Small; Filter Dark and other dark consumers may need a dark group. Not built.
  6. The set has no description and no .documentation.

Industry gaps — not added

  • Use 2–3 buttons in a group; put more into a menu button. Carbon Button
  • One primary per group, and don’t mix button sizes. Carbon Button · Fluent 2 Button
  • Vertical (stacked) group for narrow panels, primary on top. Carbon Button
  • Carbon puts primary on the left on full pages and on the right in dialogs; V1 always puts it on the right. Carbon Button
