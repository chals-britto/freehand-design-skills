Condition

A rule row built from condition fields: field, operator and value. Rows can be linked, wrapped in brackets, or joined under an And/Or tag.

Try it

Pick a type. On Linked and And/Or, add or remove rows and switch the tag between And and Or. Open any blue field to pick from the kit list. The controls on the left are page controls, not part of the component. Figma shows no add or remove control.

Usage

Types

  • Single: one rule.
  • Linked: several rules that belong together, joined by the bracket.
  • And/Or: a Linked group with the logic shown in a tag above it.
  • Brackets: part of a rule grouped in round brackets.

Behaviour

  • Each field behaves like its kit input: click or Enter/Space/↓ opens the list, ↑ ↓ move, Enter picks, Esc or a click outside closes.
  • The operator field is disabled in every Figma sample.
  • A Linked group keeps at least one row. With one row the bracket is hidden.

Figma documentation

The page's .documentation card is a copy of the Calendar card (“An interactive calendar for date selection experiences…”). It says nothing about Condition, so no usage text is taken from it.

Accessibility

Grouping

Each row is role="group" named “Condition”. The And/Or wrapper is named “Conditions joined by AND” (or OR). Brackets are aria-hidden.

Field names

Fields with no visible label get an aria-label (Field, Operator, Value). Added in build, not in Figma.

Keyboard

All from input.js. Disabled operators are skipped by Tab.

Open issues

  • The Figma .documentation card on this page is the Calendar card. There's no Condition description.
  • No add-row, remove-row, add-group or And/Or switch control exists in Figma. The Try it uses page buttons only.
  • The operator dropdown is disabled in every sample, so an operator can never be picked. Is that intended?
  • The rows repeat “Condition” three times and end with a second Value dropdown (Single). The field order looks like placeholder content, not a real rule.
  • Labels are uneven: Single keeps empty 14px label slots, and Brackets shows “Label” on only 3 of 7 fields.
  • Brackets: the first bracket cell holds two “(” texts, one 4px tall, so only one shows. The page renders one. The bracket colour is pure #000000, which is off-token.
  • The Linked bracket ticks sit at 15 / 14px, not at the 18px field centre.
  • The label colour in Figma is #737373. The kit's Condition label uses --text-light #6C6C6C. The kit value is kept.
  • The list options are the kit's “Default Option”. Figma has no option list for Condition.
  • Contrast below 4.5:1 (kept as Figma): blue value #0076DD on the field fill (#E7E7E7 30% ≈ #F8F8F8) is 4.27:1, prefix “$” #A3A3A3 on white is 2.52:1, and the disabled arrow #A3A3A3 is 2.38:1. Placeholder “Value” #737373 is 4.74:1 and passes.
  • Only Theme=Light exists.

Industry gaps — not added

  • Add and remove controls per row, and add-group, are common in rule builders. Not in Figma, not added.
  • A clear-all action for the applied rules. Carbon · Filtering asks for one on multi-category filters. Not added.
  • Nested groups (a group inside a group). Figma only nests Single → Linked → And/Or. Not added.
