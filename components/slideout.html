Try it

Slide Overlay opens below the header with an overlay behind it, sliding in from the right. Primary (the CTA) closes it and shows a toast. Secondary and the blue × just close. Esc also closes; Tab stays inside while it is open, and focus returns to the button you used.

Push Section

Push Section sits beside the page content and narrows it, with no overlay. It has no close ×: the button that opened it closes it, and so do Secondary (Cancel) and Primary (CTA, with toast).

Usage

Text from the Figma page documentation.

Uses

  • Dark theme (Fixed) — no close interaction, e.g. invoice summary, Indent Creation (domestic).
  • Dark theme (Overlay) — opens the over all screen action, e.g. upload, Comments against invoice.
  • Light theme (Fixed) — as inner section of the page.
  • Light theme (Overlay) — opens against individual items present in screen, e.g. Timeline for indent, Pickup/drop off selection, Add/Edit in masters & Settings.

Placement & convention

  • Overlay: bottom right, placed below the main header, with a background overlay.
  • Fixed: bottom right, positioned as it opens under the current section.

Interaction

  • Closing the slide out: click on the close button.
  • CTA action (depends on the context). In this kit the CTA closes the slideout and a toast confirms the action.
  • Animation: in right to left, out left to right.

Figma maps “Fixed” to Type = Push Section and “Overlay” to Type = Slide Overlay. Figma has no Dark Push Section variant, although the Uses text describes Dark Fixed — see Open issues.

Accessibility

Slide Overlay is a modal dialog

role="dialog", aria-modal="true", named by its heading (slideout.js sets this). On open, focus moves to the first control; Tab and Shift+Tab stay inside; Esc closes; focus returns to the button that opened it.

Push Section is a region

Not modal: no focus trap. Mark it role="region" with aria-labelledby on its heading. The opening button carries aria-expanded. When closed it is aria-hidden and inert.

Close and actions are buttons

The blue × is a <button aria-label="Close">. Focus ring (2px --pando-blue) added — not in Figma. Reduced motion turns the slide off.

Open issues

  • Figma has only 8 of the 12 Theme × Type × Size combinations: no Dark Push Section (the Uses text describes “Dark theme (Fixed)”) and no Push Section XL.
  • Sizes are not consistent across themes: Light overlay 440 / 740 / 800, Dark overlay 350 / 640 / 700, Push 342 / 404. Built as drawn.
  • The background overlay is described but not drawn in Figma. Used --color-overlay (Pando Dark @ 20%) — confirm.
  • The Close-Btn has no hover, pressed or focus state in Figma. Focus ring added.
  • Animation timing and easing are not in Figma (direction only). Used 240ms.
  • Push Section's Button Group uses gap 10 and a Text Only + Primary pair; the kit Button Group (Type=Buttons) is gap 20 — overridden inside the slideout (atom variant missing in kit).
  • The placeholder icon refresh-line is not in the kit icon set; drawn inline in the page (Figma SVG).
  • Placeholder colours off-token: body text #000000, Dark fill #484858 (Dark/Input BG, same as scrollbar.css).
  • Line heights: heading 14/16 (type style 19) and placeholder body 12/16 (type style 17) — kept at 16 with an override.
  • Contrast below 4.5:1 (kept as Figma): Push Section Text Only label #0076DD on the #F3F6FC header 4.2:1; Light Secondary label #0076DD on #EEF2F4 4.0:1 (kit Button). Primary white on #0076DD is 4.53:1 (passes, just).
  • The two .Panel - Swappable with Local sets (Slide out and Action pages) share this one class; check the Action copy matches before action-panel reuses it.

Industry gaps — not added

  • Click on the overlay to close — Ant Drawer (closes by default). Figma lists only the close button and CTA.
  • Footer area for actions (Fluent places primary actions in a footer) — Fluent 2 Drawer. V1 puts actions in the header.
  • Sticky header/footer that elevate on scroll — Fluent 2 Drawer.
  • Full-width size — Fluent 2 Drawer.
  • Resizable by dragging the edge, and a loading skeleton state — Ant Drawer.
  • Multi-level (nested) drawers with push — Ant Drawer. Fluent advises against several overlay drawers at once.
