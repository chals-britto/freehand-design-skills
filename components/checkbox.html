Usage

Overview

Checkboxes allow multiple selections from a set of options.

Uses

Checkboxes are used for multiple choices, not for mutually exclusive choices. Each checkbox works independently from other checkboxes in the list, therefore checking an additional box does not affect any other selections.

Placement & convention

Checkboxes can be used alone, grouped, or nested. If a group contains a mix of checked and unchecked children, the parent will show an indeterminate state.

Checkbox group added in review

  • Wrap related checkboxes in a <fieldset> with a group label (<legend>).
  • Items stack vertically, 10px apart. Nested children indent 24px so their boxes line up under the parent's label.
  • The whole label is part of the click target.

Sources: Carbon Checkbox · Fluent 2 Checkbox · Ant Design Checkbox

Error text added in review

Error is shown on each box (red stroke / fill, as in Figma) and, at group level, as one line of text under the group: --action-red, .type-11-regular. Not in Figma.

Accessibility

Native checkbox

Built on <input type="checkbox"> inside a <label>, so Space toggles it and the label text is the accessible name. With Show Label off, give the input an aria-label. Indeterminate is set in script (checkbox.js) and is announced as “mixed”.

Source: WCAG 2.2 · 4.1.2

Focus ring added in review

Figma's focus is a 1px stroke colour change. The review adds a 2px --pando-blue outline, 2px offset, on keyboard focus — not in Figma.

Source: WCAG 2.2 · 2.4.7

Group and error

Groups use <fieldset> + <legend>. The error text is linked with aria-describedby on the fieldset and the inputs get aria-invalid="true".

Open issues

  • Dark / Disabled / Selected has a stray second check mark (#234357) beside the box, widening it to 34px. Not reproduced here; delete the extra vector in Figma.
  • Indeterminate exists only for State=Default — no Disabled, Focus or Error indeterminate (6 combinations missing). Not built.
  • Light disabled colours are off-token: box #D9D9D9, selected box #9C9C9C, selected label #9C9C9C (unselected label uses --text-medium #545454).
  • Dark Indeterminate uses #66B9FF (off-token, different from the Selected fill #9CD2FF); white dash on it is 2.11 : 1.
  • Light Indeterminate dash is a cut-out, so it takes the colour of whatever is behind the box (not always white). Built that way to match Figma.
  • Focus as published is nearly invisible on selected boxes: #005399 on #0076DD is 1.72 : 1 (light), #D5DAF4 on #9CD2FF is 1.16 : 1 (dark). The added ring covers this.
  • Light unselected stroke #A3A3A3 on white is 2.52 : 1 (below 3 : 1). Dark unselected #8A8A9E on #393945 is 3.37 : 1.
  • Light Focus+Selected turns the label #0076DD; every other state keeps the label colour.
  • Dark selected states (Selected, Focus+Selected, Error+Selected) use a 11px gap; all others use 10px. Kept as Figma.
  • Label line-height is Auto in Figma (16px box); built with .type-12-regular at 17px.
  • Box is 14 × 14 — under the 24 × 24 target minimum (WCAG 2.5.8) unless the label is used.
  • Dark presentation backdrop is #393944 in Figma; shown here with --dark-bg #393945.
  • The added focus ring uses --pando-blue in both themes; on the dark surface that is ~2.4 : 1. Needs a dark-theme ring colour.
  • Figma's “Variation Examples” doc panel is empty.
