Usage

Composition

  • Cards reuse the kit: Label Readonly Text for details, Skeleton 220 Light for loading, Button Text Only (Show More), Action Button (Share, Download), Icon Button No Background, Scrollbar.
  • The Slideout Chat composes these classes. Keep them inside the chat panel.

Artifacts

  • List: one card per artifact the chat produced, with a timestamp.
  • Context: the opened artifact. "Replace Content" is a slot; the content scrolls with the kit scrollbar.

Text from Figma

Figma has no usage notes for these components. Nothing else is added here.

Accessibility

Show More / Show Less

A real <button> with aria-expanded and aria-controls pointing at the list. The label changes with the state.

Icon-only controls

Download, View, Close, Details, Clone, Accept, Reject and Upload are buttons with an aria-label (the Figma icon name). Focus ring added in review — not in Figma.

Loading

The loading card carries aria-busy="true" and an accessible name. The skeleton shimmer stops under reduced motion (kit).

Open issues

  • Line height: Figma text is “auto” (12px → 16, 10px → 14). Tokens give 12px → 17 and 10px → 12, so cards are about 2px taller than Figma.
  • Artifact name is Open Sans Bold 14; tokens.css has no .type-14-bold. Kept as a component token.
  • #404040 (detail text, artifact card text) is not in tokens.css.
  • Indicator icons Cost and Calendar are two-colour in Figma (#2D0645 + #404040, #F94200 + #422500); the kit icons are single-colour, so the whole glyph takes the main colour.
  • Context header: the Icon Button instance shows a #EEF2F4 20px background in its Default state; the kit “No Background” button has none. Kit kept.
  • Share / Download labels are #234357 in Figma; the kit Action Button is #376F99. Overridden inside the Artifacts header only.
  • Show More: Figma places the caret (#545454) next to the Text Only button; here it sits inside the button so one control toggles. The kit “Show more” molecule uses a different arrow and #0078DD, so it was not used.
  • Hover is the only interactive state in Figma. No click target is defined for a card; no Pressed, Selected or Focus state.
  • Contrast: “Quick Insights” #8A8A9E on white is 3.4 : 1; Action icon buttons #A3A3A3 on white is 2.5 : 1 (both below 4.5 : 1). Kept as Figma.
  • Close in the List and Context headers has no defined behaviour in Figma.

Industry gaps — not added

  • Expandable tiles toggle with Enter and have enabled / hover / focus / disabled states. Here only Hover exists. Carbon Tile
  • When one action is obvious, the whole card can act as a button, with focus and hover as the cue. No card-level action is defined here. Fluent 2 Card
