    Usage

    Figma has no usage text for this page. What each frame shows:

    Link chip

    A file shown as a link. Frame 2 adds a divider and × to remove it.

    File tag

    The kit File tag, with or without ×. Long names are cut with “…” (Figma sample “Averitt_NDA...”).

    Tiles

    A row of 40px tiles: one filled tile per document (a “+n” badge counts more files) and an add tile. Hover shows preview, remove and the file name.

    Document row

    Checkbox + document name + tiles, in two columns (Material screen). Ticking a row selects it.

    Accessibility

    • The list is a <ul> with an aria-label; every × and the preview are real <button>s named after the file (“Remove Packing Terms.xls”).
    • The hover overlay and remove dot also appear on keyboard focus (:focus-within); the tooltip comes from the kit tooltip.js and is linked with aria-describedby.
    • After a remove, focus moves to the next item.
    • Focus ring: 2px --pando-blue, offset 2 — added in review, not in Figma.
    • The document row uses the kit checkbox (native input).

    Open issues

    • Not a component. Everything here is built from loose frames; decide whether to componentise.
    • Atom variant missing in kit: Misc/Add-Attachment Filled · Type=File — the kit icon is PDF-only and has the remove dot baked in (Remove=Yes), so the tile is built here: 40 frame + kit file-type icon at 10,8, as the Figma instance is made.
    • Atom variant missing in kit: Misc/Add-Attachment Filled · Type=Image — uses .pds-card__thumb with a grey placeholder (photo not exported).
    • Atom variant missing in kit: Tooltip Single Line hugs its text in Figma (95 wide, 4 8 padding); the kit tooltip is 164 wide fixed with 10 padding.
    • Tile frame colour: tiles inside the Material screen render #E2EAEC frame / #CBD4D8 plus; the standalone instances and the kit icon use #B5C3CB. Kit kept.
    • Badge “+1” text is #404040 in the screen; kit Count badge uses #313131.
    • Off-token colours: hover overlay #000 @ 80%, row label #404040, Selected row fill #EBF1FA.
    • Chip name is Open Sans Italic 12/16 underlined — no italic .type-* style exists.
    • Row grid: the frame declares a 10px column gap but the two 306 rows sit 6 apart inside a 618 frame; 6 used.
    • Gap between chips/tags in a list is not shown in Figma — 10 used (added in build).
    • Behaviour is added in build — not in Figma: add tile opens the file picker, preview fires an event (no viewer), remove deletes the item, extra files raise the “+n” badge.
    • Missing states in Figma: uploading, error, disabled, empty list, Dark theme for chips/rows (kit has Dark add tiles only).
    • Contrast: row label #404040 on #EBF1FA passes; #B5C3CB tile frame and divider are about 1.8:1 on white (non-text, below 3:1).
