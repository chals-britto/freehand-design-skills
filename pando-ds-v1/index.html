Pando DS V1 Library

Every token here comes from tokens.css in the pando-ds-v1 repo and was kept in the Foundations review. Click any swatch to copy its CSS variable. Build with roles (--color-*); use the palette only when no role fits.

Colour roles

The job each colour does, taken from the “Used:” notes in Figma. Components should only reference these.

Palette

Raw colours. “No role” means Figma doesn’t say where it’s used yet.

Status & tags

Figma rule: light = background, medium = border, dark = text. Used in status, tags, dashboard filters and indicator icons.

Gradients

“Inferred” names were matched by colour because the swatch isn’t linked to a style in Figma.

Type scale

Open Sans. A style is size + weight + line-height; colour comes from roles. Add .caps for ALL CAPS (uppercase + 0.5px tracking, 1px on 14px).

ClassSpecSampleReplaces (Figma roles)

Elevation

Four shadow styles from the Figma “Shadow” section, ordered low to high. Usage per level is set as components are reviewed.

Contrast pairs

Text-on-fill combinations used in V1 today, measured against WCAG AA (4.5 : 1 for normal text). Failures are fixed in the accessibility pass after the system is complete.

SampleTextFillRatioAA

Components

Every component built from Figma, as a spec page: live components, states, spec values, usage, open issues and code. “As in Figma” = built without a review; use the Flag buttons on any page to pin a comment where something is wrong.
