AI Side Bar

The chat-history side bar of the AI assistant: New Chat, Search, and the Starred and Recent chats. It collapses to a 50px rail. Figma has no written description; this is drawn from the component.

Try it

Click the Grid View icon to close or open the bar (hover it for the tooltip). Click a chat to select it. On this page the ⋯ button pins or unpins the chat, moving it between Starred and Recent; Figma draws no menu for ⋯. Keyboard: Tab to the chats, ↑ ↓ Home End move between them, → goes to ⋯, ← comes back.

Usage

Figma has no usage text for this component. The cards below describe what is drawn.

What is drawn

  • Header: Freehand AI mark, assistant name, Grid View toggle.
  • New Chat and Search as Action Buttons.
  • “Starred” and “Recent” chat groups.
  • One chat is Active.

Open and closed

  • Open (270): everything shown. Hovering the toggle shows “Close Sidebar”.
  • Closed (50): the AI mark plus icon-only New Chat and Search. Hovering the header swaps the mark for the toggle and shows “Open Sidebar”.
  • No animation is drawn.

Chats

  • One line; long titles end in an ellipsis. The full title is the link’s title (added for the kit).
  • ⋯ More Actions shows on hover and on the Active chat. What it opens is not drawn.

Accessibility

Structure

A <nav aria-label="Chat history">. Each group is a heading plus a list. Chats are links; the current one has aria-current="page".

Keyboard (added for the kit)

The toggle, New Chat and Search are buttons. The chats are one Tab stop: ↑ ↓ Home End move, → reaches ⋯, ← returns, Enter opens. Focus ring 2px --pando-blue — not in Figma.

Toggle

Icon-only button with aria-label “Close Sidebar” / “Open Sidebar” and aria-expanded; the kit tooltip repeats the label on hover and focus. Closed, New Chat and Search keep their text for screen readers.

Open issues

  • Off-token colours: tint #FFEFE5 (22% open, 32% closed — two different values), title #1E1815.
  • Title font BL Pylon Serif Medium 14 is not in tokens and not loaded; falls back to Georgia. Line height is auto in Figma (19 used).
  • AI mark is an inline vector (#FE6505 = --freehand-orange), not a kit icon. Indicator Icon/AI, an “ai-wand” frame, a “Freight Pay Specialist” title and a Dropdown-Arrow sit hidden in the header — an unbuilt agent switcher?
  • Indicator Icon/Pin is hidden in the Starred heading; nothing shows how a chat gets pinned. pin() and the ⋯ wiring on this page are kit additions.
  • ⋯ More Actions opens nothing in Figma (no menu drawn).
  • Search is an Action Button only; no search field or filtered state is drawn, so none is built (kit search-input not used).
  • Action Buttons are kit Action Buttons with instance overrides: 36 tall, padding 10, gap 8, 13 SemiBold #313131, title case (the kit atom is 22 tall, 12 SemiBold #376F99). Their hover is the kit’s (#E9F1F5) — not drawn here.
  • The kit Tooltip Text is 164 wide; here it hugs its text (104), set by .pds-ai-sidebar__tip.
  • Item text 12/16 vs .type-12-regular 12/17; heading 10 SemiBold with 0 tracking vs .type-10-semibold +0.5.
  • .Menu-Item master is 240 wide; used at 250 in the bar. Hidden Code 01 / ID 01 / Sub text layers have no component property.
  • No focus, pressed or empty states in Figma. Empty groups are hidden (kit rule).
  • Contrast under 4.5:1: headings #8A8A9E on the tinted bar ≈ 3.3:1; Grid View #A3A3A3 ≈ 2.5:1 (non-text, under 3:1); Search icon #8A8A9E ≈ 3.3:1.
