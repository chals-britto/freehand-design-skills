Usage

From Figma

Figma has no usage text for these sets. What the variants show:

  • User messages sit on the right with no avatar; AI messages and the Loading dots sit on the left after the avatar.
  • Swapable = yes adds the Swappable Content slot under the text (200px bubble).
  • The AI bubble shows a skeleton while loading, then the “Pi Summary” with content and buttons.
  • PI names the agent (FAP or Procurement) and shows a dropdown arrow.

Composition

  • The AI Chat window (later) composes these classes; each block is self-contained.
  • The slot inside bubbles and the AI bubble is .pds-comment-thread__slot from comment-thread.css.
  • The AI bubble loader uses .pds-skeleton--180.pds-skeleton--dark from skeleton.css.

Motion

  • Typing dots and the loader run in CSS only.
  • With prefers-reduced-motion they hold their first frame.

Accessibility

Loading states

Typing dots and the loader carry role="status" with aria-label="Loading" — added in review, not in Figma.

Controls

.button and PI are <button type="button">. Focus ring 2px --pando-blue, offset 2 — added in review, not in Figma. Avatars and icons are decorative (aria-hidden / empty alt).

Times

Use <time> for the message time.

Open issues

  • Contrast: Light AI time #D5DAF4 on white 1.4:1 (Figma uses the dark-theme colour); PI Dark FAP hover #FFA600 on #EEF2F4 1.7:1; .button Red #E25757 on #24242F 4.2:1; light typing dots (#9CD2FF 50%) on white 1.3:1. Kept as Figma.
  • Light User bubble is #FFF4E5 but Light User + Swapable = yes is #B5E4FF. Kept as Figma.
  • Dark PI hover differs by Type: FAP turns light (#EEF2F4), Procurement turns black 80%. Kept as Figma.
  • No Light + FAP PI variant; PI On-click has no destination (the dropdown it opens is not defined).
  • Line heights: bubble text Figma 12/18 → .type-12-semibold 17 (Light AI is 12/auto); .button 11/auto → .type-11-regular 15; “Pi Summary” 12/auto, 0.3px tracking (not the 0.5px .caps). PI label Bold 14/16 has no type style.
  • Off-token colours: #484858 (bubble / typing fill), #0078DD (light typing dot, Pando Blue is #0076DD), #FFA600 (PI dark label and icon), black 80% (PI hover).
  • Atom variant missing in kit: Header-Logo/Apps › Freehand, Variant=AI-Yellow (4405:7109) — inlined on this page, fill --status-brown-medium.
  • Not kit atoms, inlined: “Freehand_Ai_Icon 1” (PI dark) and “ai-wand 1” (PI light) are loose frames inside PI, not icon components. refresh-line slot icon inlined as on the Comments page.
  • Typing dots: the composer organism owns .typing dark / .typing light (9 frames). Built here as .pds-ai-bubble__typing because Chat bubble needs it; dedupe when ai-chat-composer lands. Light typing padding is an instance override (8/15; main is 8/20).
  • Typing frame 9 → frame 1 has no transition in Figma (instant jump); kept.
  • “DP” (User dark) and “Text Avatar” (User light) are hidden in every variant with no property to show them, so the user avatar is not built.
  • The Loading bubble's “Bubblechat” wrapper has a 0-width #EFEFEF stroke and radius but no fill — not rendered.
  • Loader art is exported from the Loader's own instance; the main Pi-With Halo › Freehand also carries yellow AI stars that the Loader hides.
