Search Input

A 36px search field with a results list of Dropdown Option rows. Light has Empty, Filled, Active (open list) and Categories (grouped list with checks); Dark has Empty. Figma has no written description; this is drawn from the component.

Usage

States

  • Empty / Filled: closed field.
  • Active: typing opens the results list (rows with an Icon Avatar).
  • Categories: results grouped under headings; picked rows show a blue check (rows have no avatar).
  • Dark: Empty only, no search icon.

From the variants only — Figma has no usage text.

Where it is used

Calendar, Filter Light, .group light and Search chat (Molecules inventory).

Built from

Rows are .pds-dropdown-option (dropdown-option.css) with the kit Icon Avatar; category headings are .pds-menu__section (menu.css) with the heading colour set to #6C6C6C; icons from components/icons/.

Accessibility

Roles

The input is role="combobox" with aria-expanded, aria-controls → the role="listbox" panel, and aria-autocomplete="list". Rows are role="option" + aria-selected; headings are presentational. Categories sets aria-multiselectable. The field needs an accessible name (aria-label) — Figma shows no visible label.

Keyboard

Focus stays in the input. ↓ opens / moves, ↑ moves, Enter picks the highlighted row (aria-activedescendant), Esc closes. The clear × is a real button (“Clear search”). Focus outlines are added — not in Figma.

Contrast (for the a11y pass)

Placeholder #6C6C6C on #F8F8F8 5.0 : 1. Value #313131 on #F8F8F8 12.6 : 1. Search icon #A3A3A3 on #F8F8F8 2.4 : 1 (below 3). Active border #E2EAEC 1.2 : 1. Dark placeholder white 60% on #484858 ≈ 3.9 : 1 (below 4.5). Field fill #F8F8F8 vs white 1.06 : 1 — the closed field has no visible edge on white.

Open issues

  • Atom variant missing in kit: input.css has no 36px search field (its fields are 60 high with a label). The field is built inside this component.
  • Behaviour is not in Figma. Figma only shows static states. Built: typing filters, ↑/↓/Enter/Esc, click outside closes, clear × shows while there is a value (Figma has only the Show Close Icon boolean, default off). Categories toggles checks and stays open — assumed from the checks shown.
  • No empty / no-results state in Figma: the panel simply closes when nothing matches. No loading, disabled or error state.
  • Categories field: the search text layer is removed in the instance (icon only), the border is #0076DD where Active uses #E2EAEC, and the shadow (0 2 14 10%) sits on the whole frame; built on the panel. Active’s panel uses a different shadow (0 14 28 6%).
  • Heading colour: Option Heading is #6C6C6C; the menu atom section heading is #313131. Reused .pds-menu__section with --menu-section-fg overridden.
  • Dark: Empty only — no icon, no Filled/Active, no list. Typed text colour (white) is added — not in Figma. Width 279.3 fixed (built 279). Off-token #484858 and white 60%.
  • Search icon: Figma’s Navigation/Search-10px draws #A3A3A3 over #8A8A9E inner paths; built #A3A3A3.
  • Line heights: 16 in Figma (Active text Auto) vs 17 in .type-12-*; set to 16px so the field stays 36.
  • .Search Dropdown is 7 rows (392) with no scrollbar; a max-height of 392 with scroll is added — not in Figma. Its rows inherit the dropdown-option open issues (avatar glyph colour, #737373 contrast on hover).
  • Text props “Placeholder Text” and “Search Input” both default to “Search Input”.
