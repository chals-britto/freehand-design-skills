Slideout Chat

The full AI drawer: a header, a welcome block with Quick Insights and Quick Actions, a swappable slot for the conversation, and the prompt input. It opens as a slideout or fills the page. Figma has no description text on this set.

Try it

Opens in the kit Slideout overlay layer (slideout.js: slide right → left, overlay, Esc, focus trap, focus back to the trigger). Inside, the flow is a demo only — no AI is connected: pick an insight card or a Quick Action → Swappable=Yes with an Action popup in the slot → Confirm shows Responding; Skip shows the input's Skipped state; sending from the bar shows Responding; + (New chat) goes back to the start. Demo content is outlined with a dashed line.

Accessibility


    
  
  • The chat is an <aside> named “Freehand AI chat”; in the drawer the .pds-slideout wrapper gets role="dialog" + aria-modal from slideout.js (named by aria-label, as there is no heading element).
    • 
  
  • Icon buttons are named Menu, New chat, Details, Expand, Close. Close carries data-slideout-close.
    • 
  
  • Insight cards get role="button" + tabindex="0" (Enter / Space) and Quick Actions are <button>s — added in review, not in Figma.
    • 
  
  • The slot is aria-live="polite"; Responding is role="status" (kit).
    • 
  
  • Focus ring 2px solid --pando-blue, offset 2 — added in review, not in Figma.
    • 
  
  • Contrast for the accessibility pass: “Quick Actions” / “Quick Insights” #8A8A9E on #FFFBFA ≈ 3.4:1 · description #737373 on #FFFBFA ≈ 4.6:1 (passes) · divider 1.2:1 (decorative) · send off white on #CBD4D8 ≈ 1.5:1 (kit).
    •
