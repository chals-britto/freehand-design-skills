Usage

Which variant

  • Single (Light) / Left (Dark): one group of options. Light Single has no buttons in Figma; Dark Left has RESET / APPLY in a footer.
  • Multiple: several groups. Pick a group on the left; its options show on the right with a search field.

Behaviour

  • One group is always open. Opening another closes the current one and clears the search.
  • Group header count = options picked in that group; hidden at 0.
  • RESET clears every group. APPLY hands the selection to the page (event pds-filter-panel:apply).

Behaviour is not drawn in Figma — built from the static states. See Open issues.

Where it is used in Figma

  • “Invoice landing” frame on the same page: Filter Dark / Left.
  • “Frame 483113”: Filter Light / Single.

Accessibility

Structure

The panel is a region labelled “Filter”. Group headers are the kit Accordion buttons (aria-expanded, aria-controls → the options pane); their accessible name includes the count (“Vendor, 2 selected”).

Options

Multiple: native checkboxes inside a group. Single: radiogroup of buttons with role="radio" and aria-checked; pressing a chosen option again clears it. Search has the label “Search options”.

Open for the accessibility pass

Light count badge white on #0078DD ≈ 4.6:1 (borderline). Dark Hover (#24242F) is invisible on the Dark Multiple pane (#24242F). No focus visual in Figma; a blue 2px ring is added on Single rows.

Open issues

  • Page status: the Figma page is named “Filter - To BE REVIEWED” and has no status emoji. Everything here is built as published; confirm before treating as standard.
  • Light Single Selected is not in Figma. .options light has Single Default and Hover only. The Try-it uses the Dark Single Selected pattern (label + check) in Light colours so the choice is visible — added in review — not in Figma. Variants show only what Figma has.
  • Stray variant: .options light contains “Theme=Dark, Type=Single, State=Default” (32 tall, padding 8) — a duplicate of the .options dark one (36 tall, padding 10). Rendered both; the panel uses the .options dark one.
  • Dark Multiple uses an unpublished option component (“.options light/Dark/Multiple/Default”) with 0 left padding; the published .options dark rows have 10. Built as drawn (0).
  • Atom variant missing in kit: the group count badge (14px circle, #0078DD / #1FCD93). badge.css count is 16px #B5C3CB. Built inside this component. #0078DD is off-token (same override as Show more).
  • Instance overrides of kit atoms: Light open Accordion heading #404040 (kit #313131, off-token); closed Accordions have the arrow hidden (kit shows it); Button Group gap 10 (kit 20); Dark Search Input is the Light instance recoloured (fill #484858, text/icon #D5DAF4, 36 tall) — the kit Dark search is 32 tall with white @60% placeholder.
  • Kit bug found: search-input.js throws when the clear × is pressed on a field without a results panel (it calls filter() on a null panel). This component wires its own search + clear instead of pdsSearchInput.init.
  • Line heights: option label 12/Auto = 16 (kit .type-12-regular 17); Section Header 10/Auto = 14 (kit .type-10-semibold 12). Kept Figma heights in component tokens.
  • Not in Figma: behaviour (open/close, search, count, reset/apply), no-results state for search, scrolling (Figma shows a Dark scrollbar only), focus, disabled options, loading.
  • Hidden layers in .group (booleans off): Section Header filter icon and text button, Search Input, extra 3 options, footer text button — not built as options; ask whether they are needed.
  • Light Single has no RESET / APPLY, unlike Dark Left. The Light Single Options frame (250 wide rows) overflows its 200px parent in Figma; built at 200.
  • Hover on Dark Multiple pane is the same colour as the pane (#24242F) — no visible hover there.
