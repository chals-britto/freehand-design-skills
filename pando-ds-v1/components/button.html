Button

Buttons are clickable elements that are used to trigger actions. Button labels express what action will occur when the user interacts with it.

Usage

Primary

For the principal call to action on the page. Primary buttons should only appear once per screen (not including the application header, modal dialog, or side panel).

Secondary

For secondary actions on each page. Secondary buttons can only be used in conjunction with a primary button.

Text Only

As part of a pair, the text button performs the negative action of the set, such as Cancel or Back.

Other types

  • Icon button — the icon gives a visual clue and fits more buttons in a small space. Icon-only buttons need a tooltip.
  • Button Dropdown — a label with a dropdown icon that opens more options.
  • Dual icon — two icons in one compact element.
  • Action button — text that prompts an immediate action.

Placement & convention

Buttons on Pando are generally placed to the right of the screen and should be immediately visible without scrolling. In a contained button the label is always centred.

Do & don’t

  • Do: emphasise the primary action. If there is no primary action, a default button is the safest choice.
  • Don’t: put more than 1 primary button in the same group.
  • Don’t: put 2 icons in the same button (conflicts with Dual Icon — open issue).

Source: Figma “Button” doc frame (5554:25032)

Danger tone added in review

For destructive actions. Uses Figma’s Red treatment on Secondary, Text Only and Action. Disabled wins over the tone. Not on icon-only buttons. No Primary danger yet (no Figma visual).

Sources: Carbon Button · Ant Design Button

Loading added in review

Vector spinner in the label colour. The button is disabled while loading and keeps its label and focus. Call pdsButton.setLoading(btn, true).

Sources: Carbon Button · Ant Design Button

Icon-only buttons added in review

Always give an aria-label and a tooltip with the same words. pdsButton.check() warns when a name is missing.

Sources: Carbon Button · WCAG 4.1.2

Accessibility

Keyboard and focus

Use <button type="button">; Enter and Space press it. Focus ring: 2px --pando-blue, 2px offset added in review — not in Figma

Sources: WCAG 2.4.7 · WCAG 1.4.11

Names and states

  • Icon-only: aria-label; icons are aria-hidden.
  • Loading: aria-busy + aria-disabled, focus kept.
  • Split caret: aria-haspopup="menu" + aria-expanded.

Open issues

  • Hover and Loading look the same; Loading only adds the spinner. Hover inverts instead of darkening; --pando-blue-active is unused.
  • Secondary Hover is the same as Primary Hover.
  • Normal vertical padding is uneven (6 top / 8 bottom); Small is 5 / 5.
  • Secondary “Green” is the Default button plus a #1FCD93 dot at the top-right corner, not a colour tone. Purpose unclear.
  • Red / Green are States in Figma, so they can’t combine with Hover or Disabled. Built here as tone modifiers.
  • Text Only hover fill hugs the text (no padding). Dark Text Only has no Hover.
  • Action Hover and Active are identical; radius 0 at Default, 4 at Hover. Only Normal size.
  • Disabled #9C9C9C (Icon Button, pill) is not in tokens.css.
  • Icon Button: shadow style is named 0-1-3 but is 0 2 3; every circular state carries it (Normal Default twice). No Background Hover’s white circle is invisible on white.
  • Pill “Loading” is a brown-light fill with no indicator — reads as a selected chip. Built as .is-selected; needs a name.
  • Dropdown has no Hover or Disabled. Active variants bake an open menu into the button (menu not built here). Small Loading spinner is 16px. Split Small caret segment is 26 wide (Default) vs 24 (Active).
  • Dual Icon Circular: Normal/Default and Small/Active are the same; padding 10 inside a 24px frame. “Don’t put 2 icons in one button” conflicts with Dual Icon.
  • AI Copilot: gradients (#E03A8A, #FE6505, #FF8C54, #8D00DF, #FF4DA6) and the 14px SemiBold label are not V1 tokens or styles; a hidden “AI-Powered Suggestions” layer sits in Hover.
  • Show more: label #0078DD is off-token; “Show more” vs “Show Less” casing; arrow set has placeholder states “State3” / “State4”.
  • Dark coverage is uneven: no Dark Normal Loading, no Dark Normal Red.
  • Line height: Normal labels use 16px (Figma auto) vs .type-12-bold 14px; Action 16px vs .type-12-semibold 17px.
  • Placement text in Figma is missing a word (“right of the screen should be”).
  • Target size under 24px: Small icon 20, Text Only 14–16, Action 22 (Later).
