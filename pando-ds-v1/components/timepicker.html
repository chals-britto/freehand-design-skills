Try it

Click the field (or press ↓ in it) to open the picker. Scroll a column, click a value, or use the arrow keys; Enter applies, Esc cancels. The value in the band is the one that is applied.

Usage

From Figma

“Adjust the Selection Border padding to suit the width of the dropdown. 10px padding on Left and Right.” — the band is inset 10px each side, so it follows the panel width.

Opening from a field

  • pdsTimepicker.attach(input) opens the panel under a kit input, as wide as the field (min 160).
  • Apply writes HH:MM (24-hour) into the field. Cancel, Esc or a click outside leave it unchanged.
  • While open, the field shows its Active border.

Behaviour added in review — Figma shows the panel only.

Format

  • 24-hour, hours 00–23, no AM/PM (Figma has none).
  • Minutes in steps of 5. A typed value between steps rounds down.

Accessibility

Roles

Each column is a listbox (“Hours”, “Minutes”) with aria-activedescendant on the value in the band. The attached panel is a dialog (“Choose time”); the field gets aria-haspopup, aria-expanded, aria-controls.

Keyboard

  • ↓ in the field opens the panel and focuses Hours.
  • ↑ / ↓ change the value, Home / End jump to first / last.
  • ← / → switch column. Tab reaches Cancel and Apply.
  • Enter applies, Esc cancels; focus returns to the field.

Open for the accessibility pass

Focus ring on a column (2px --pando-blue inset) is added in review — not in Figma. Cancel and Apply keep the kit button contrast notes.

Open issues

  • Figma draws hours 00–18 only (the column is clipped); built as 00–23 since the list runs past 12. Confirm 24-hour is intended — no AM/PM in Figma.
  • No visual difference for the selected value — only the band lines mark it. No hover state for values in Figma.
  • Colon is #000000, not in tokens.css (values use --text-dark #313131).
  • Column padding is 15px in Figma; extended to 67px top and bottom so 00 and the last value can reach the band (added in review).
  • Value line height: Figma uses auto (16px rows); .type-12-semibold is 17px — overridden to 16px.
  • Cancel and Apply render in the kit button’s uppercase. Figma copy is “Cancel” / “Apply”; check the button text case.
  • Attached width: Figma is 160 fixed; the attached panel takes the field width (min 160), per the Figma note about the band padding. Confirm.
  • No disabled times, no “Now”, no typed entry inside the panel in Figma.
