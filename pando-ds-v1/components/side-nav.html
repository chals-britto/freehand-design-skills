Usage

What it is for

Used as Navigation for within a page/section. One icon per section; exactly one is active.

Page shell

The rail sits on the left edge under the Top Header and runs to the bottom of the page. Content starts right of the 40px rail.

Icons

Figma sample: Global shipment, Cost, Cartons, Details, Load-Material, Sustainability, AI — all kit Indicator icons. Swap the icon per item (Figma property “Icon”).

Accessibility

Landmark and names

Use <nav aria-label="…"> with a list of links. The items have no visible text, so each needs aria-label (the section name). Icons are aria-hidden.

Current item

side-nav.js puts aria-current="page" on the active item (set data-current="location" on the nav for in-page sections) and removes it from the rest.

Keyboard

One Tab stop. ↑ / ↓ move between items and wrap. Enter selects. Focus ring added in review — not in Figma.

Open issues

  • No visible labels and no tooltip in Figma — sighted users must guess what each icon means. Names exist only for screen readers (aria-label).
  • No Hover state in Figma (only Default and Active).
  • No focus state in Figma — focus ring added in review.
  • Active vs Default differ only by the fill: white #FFFFFF on #D9E6FF is 1.3 : 1 — below the 3 : 1 non-text contrast guide. Kept as Figma.
  • The AI item in Figma uses Indicator Icon/AI · Size=14px stretched to 20px; the kit renders that same 14px icon at 20px. A 20px AI icon exists in the kit.
  • Figma frame height 658px is a sample; the kit rail fills its container.

Industry gaps — not added

  • Expand / collapse toggle (hamburger) to show the labels. Fluent 2 Nav
  • Tooltip with the item name, placed to the right of the item so it does not cover the next one. Fluent 2 Nav
  • Grouped sections / sub-items (categories that open). Fluent 2 Nav · Carbon UI shell left panel
