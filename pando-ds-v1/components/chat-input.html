Chat Input Box

Chat Input Box allows users to enter and send text-based messages. It supports message composition and sending attachments.

Try it

Type to grow the box. Enter sends, Shift + Enter adds a new line. “Add” turns on once there is text or an attached file. Click # Add Tag, type a tag and press Enter. The clip opens the file picker; each file gets a removable tag.

From the page’s .documentation card in Figma.

Usage

Used in various modules to compose the message in chat/comments.

Placement & convention

  • Fixed at bottom of the screen or pane.
  • “Add comment here” placeholder text.
  • Quick access icon as attachment.
  • “Send” button on the right side; it enables once the box has a minimum character or attachment. (The button reads “Add” in every variant.)

Sending a message

  • Click the “Send” button or press Enter to submit the message.
  • Press Shift + Enter for a new line without sending.

Error handling

If a message fails to send (e.g. network issues), an inline error message appears, prompting the user to retry. No visual for this in Figma — not built (see Open issues).

Also known as

Chat · Comments · Message · Comment Box · Chat input box (set description).

Accessibility

Field

The text area is role="textbox" with aria-multiline="true" and the label “Comment”. Give it a page-specific label (e.g. “Comment on INV-20431”) where several boxes share a page.

Keyboard

  • Enter sends, Shift + Enter new line (Figma).
  • Tab order: tag → text → clip → file tags’ × → Cancel → Add.
  • Tag name: Enter keeps it, Esc cancels (added in review — not in Figma).

Buttons

The clip is a <button> labelled “Attach file”. Each file tag’s × is labelled “Remove <file name>”. “Add” uses the native disabled state until there is text or a file.

Focus

Focus ring 2px --pando-blue, offset 2px, on the text area, tag, clip and × — added in review, not in Figma.

Contrast (for the accessibility pass)

  • Disabled #A3A3A3 on #F8F8F8 ≈ 2.4:1; on #484858 ≈ 3.5:1.
  • Light placeholder #6C6C6C on white ≈ 5.3:1 (passes).
  • Dark placeholder #8A8A9E on #393945 ≈ 3.4:1.
  • Clip #D5DAF4 on #484858 ≈ 6.9:1 (passes).

Open issues

  • The documentation says “Send”; every variant’s button reads “Add”. Built as “Add”.
  • “Cancel” is Disabled in all 10 variants, Filled included. What Cancel does (clear? close?) is not stated. Built always disabled.
  • Dark Filled “Add” is a Disabled Text Button instance with a #1FCD93 fill override. The kit has no green Dark Text button — set in chat-input.css (atom variant missing in kit).
  • Text area is a fixed 100px in Figma. Built as min 100px that grows with the text; no max height or scroll rule in Figma.
  • The inline error (“message fails to send … retry”) has no visual or copy in Figma. Not built.
  • Tag=Edit shows “# |” only. Tag-name suggestions, a list, or how to remove a committed tag are not shown. Built: Enter keeps the tag, Esc/empty returns to “# Add Tag”, Backspace at the start removes the committed tag (browser default).
  • “Show Attached File” tag text (“Tag Text”) and its left icon are hidden in every variant, so only the instance properties were readable. The kit attachment tag’s PDF icon is used.
  • One variant (Light · Empty · Tag=Yes) uses a detached “Buttons” frame instead of the Button Group instance. Same look; built with the Button Group.
  • Light has no fill at all — the box shows whatever surface it sits on.
  • Off-token: #484858 (Dark border and bar).
  • Typed text line height: Figma 12/18, built with .type-12-regular 12/17 (inherited from .pds-comment).
  • Placeholder is 12 Italic; tokens.css has no italic text style (font-style set in the component).
  • No hover, focus or disabled state for the whole box in Figma.
