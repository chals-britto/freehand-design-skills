Breadcrumb

Breadcrumbs show users their location during navigation and allow them to easily move up a level or levels in a hierarchy of pages.

Usage

Text from the Figma documentation.

Uses

  • Place breadcrumbs in the top left corner, typically above the page title.
  • Show progress from the highest navigation level to the lowest, without skipping a step.

Placement & convention

Used on the sub-header.

Accessibility

Structure

<nav aria-label="Breadcrumb"> around an ordered list. The current level has aria-current="page". Carets are hidden from assistive tech.

Keyboard

Earlier levels are links (Tab, Enter). The Dropdown current level is a button with aria-haspopup; Figma has no menu, so none is wired.

Contrast

#545454 on white 7.6 : 1 · #005399 on white 7.8 : 1 — both pass. No focus style in Figma (browser default ring shown).

Open issues

  • The Figma current-level text is “ Current” with a leading space. Built without it.
  • Default has a hidden caret before the Status tag with no property; Status and Match Type follow the current level 10px apart with no separator.
  • Match Type frame has a hidden #FFEAEE @ 30% fill and a 0 2 2 0 radius — looks unfinished.
  • Status tag text style taken from the shared Tag Small (10px SemiBold); not read on the instance itself.
  • Dropdown has no open state, menu or hover; no focus, disabled or truncation states anywhere.
  • Match Type line-height is “auto” in Figma vs 12px in .type-10-semibold.

Industry gaps — not added

  • Overflow: collapse middle levels into an overflow menu; never wrap to a second line. Carbon · Fluent 2
  • Small and medium sizes. Carbon Breadcrumb
  • Label truncation (30 characters) with a tooltip. Fluent 2 Breadcrumb
  • Disabled (focusable) level for hierarchy steps without a page. Fluent 2 Breadcrumb
  • Reflow: show only the last level at 400% zoom / small viewports. Fluent 2 Breadcrumb
  • Location- vs path-based breadcrumb guidance. Carbon Breadcrumb
