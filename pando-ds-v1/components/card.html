Usage

Where it is used (Figma)

Cards used in Documents, Procure, Settings, Dashboard Widgets.

Heading style note (Figma)

  • 12px heading with subheader — icon
  • 14px heading / no subheader — no icon

Loose text on the Card page (1335:4363). No 14px-heading variant exists in the set, so none is built.

Atoms inside

  • Icon Avatar → avatar.css
  • Tag (Small, Filled, Purple) → tag.css
  • Badge Count → badge.css
  • Input - Text → input.css / input.js
  • Icon+Action (Fetch, Edit) → button.css Action button
  • Multiselect Number Only → tag.css .pds-tag--count
  • Icons → icons/

Accessibility

Structure

Use an <article> for each card with the heading as its name (aria-labelledby). Settings rules are a list (<ul>).

Actions are buttons

Fetch and Edit are real <button>s (kit Action button), so they are reachable with Tab.

Contrast (for the accessibility pass)

#1FCD93 heading on white 1.9 : 1 (Light Empty) · #A3A3A3 description on white 2.5 : 1 · #8A8A9E on #24242F 5.0 : 1 · #6C6C6C carrier on white 5.3 : 1. Kept as Figma.

Open issues

  • Atom missing in kit (remote library): Unit/Small — built inside card.css as .pds-card__unit.
  • Atom missing in kit (remote library): Rule — built inside card.css as .pds-card__rule; its hidden “Property 1=Default” variant is not built.
  • Atom missing in kit (remote library): Circular Indicator (Color=Cyan, Type=Depot Manager) — built as .pds-card__indicator; fill #D9E6FF @ 70% differs from the kit Icon Avatar cyan (#BDF0F4).
  • Remote Multiselect (Type=Number Only) matches the kit Multiselect Tag exactly (22px, padding 4/10, radius 12, 2px #E2EAEC) — reused .pds-tag--count, nothing rebuilt. Confirm they are the same component.
  • Atom variant missing in kit: Misc/Add-Attachment · State=Filled · Type=Image (with Badge +3) — built as .pds-card__thumb. The photo was not exported; the #C4C4C4 mask fill stands in.
  • Dark · Single · Empty keeps a white outer card fill under the dark section (visible only at the 2px corners). Kept as Figma.
  • Dark · Single · Active draws its icon as a plain ellipse group, not the Icon Avatar instance used everywhere else.
  • Stat-layer tags carry no label text in Figma (empty purple tags 18px and 45px wide) and the value is “-”. Rendered as-is.
  • Card/Settings header: Figma’s 64px gap overflows the 375px row (Edit lands outside). Built with Edit pushed to the right edge instead.
  • Card Documents inputs: label #616161 and placeholder #737373 in the instance; kit Input uses its own tokens. Kit values win.
  • Off-token colours: Tag Info value #5A6277, Consignment text #404040, image mask #C4C4C4.
  • Line-heights: Figma uses “auto” on 12px semibold headings (≈16px); .type-12-semibold is 17px. Body Text and rule values are 12/16 (no type class — set inline in card.css).
  • No focus, selected or disabled state in Figma for any card; Consignment has Hover only.
