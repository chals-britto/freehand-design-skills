Table Cell

Table data to show or add text, tags or dropdown inputs. One cell for each column type: text, inline-edit text, header, input header, tag and dropdown, in light and dark, with alternate, child and disabled backgrounds.

Try it

A table composed only from Table Cells. Click an Input Text cell to edit it (Active ring), clear it to see Empty, open a Dropdown cell, tick a checkbox. Checkbox, icon, filter and sort are the cell's on/off properties.

Usage

Types

  • Text: read-only value, one or two lines.
  • Input Text: the cell is an inline text field.
  • Header / Input Header: column titles.
  • Tag: count + unit tag.
  • Dropdown: pick a value in the cell.

Figma description: “Table data to show or add text, tags or dropdown inputs.” The rest is from the variant names.

Backgrounds

  • Default and Alternate rows alternate down the table.
  • Child: rows nested under a parent row (Text only).
  • Disabled: Text and Input Text.

Accessibility

Semantics

Use the classes on real <th scope="col"> and <td>. Input Text cells hold a native <input> — give it an aria-label (the column name). Dropdown cells use the Table Dropdown combobox.

Focus

An Input Text cell shows its Active ring on focus. Sort / Filter buttons in headers get a 2px --pando-blue outline — added in review, not in Figma.

Open for the accessibility pass

Dark header text #8A8A9E on #343440 is 4.0 : 1; Dark disabled #8A8A9E on #393945 3.8 : 1; Filter arrow #6D8EB4 on white 3.4 : 1. Light disabled text #6C6C6C passes (5.0 : 1).

Open issues

  • Dropdown cells use the private copy .Table Dropdown (2343:6642), not the public Table Dropdown 2711:10723. Built with the kit (public) Table Dropdown; the Active list therefore positions absolutely instead of in the flow.
  • Dropdown sample text: “Select Dropdown” in four cells but “Select Option” in Light · Alternate. Rendered as Figma.
  • At the Figma sample width (140) the placeholder “Select Dropdown” truncates in the browser (italic Open Sans is synthesised; Figma fits it in 94px). Demo uses 150.
  • Dropdown Active: the field moves from centred to 10 from the top, and (from Table Dropdown) 10px right, when the list opens.
  • Light Dropdown fills the cell (arrow on the right, padding right 10); Dark Dropdown hugs its text (padding right 8). Kept.
  • Dark Alternate fill (#393945) is lighter than Dark Default (#343440), and the same fill as Dark Disabled — Dark disabled cells cannot be told apart from Alternate rows except by text colour.
  • Light Input Text · Disabled keeps #313131 text (only the fill changes); Text · Disabled turns the text #6C6C6C. Inconsistent; kept.
  • Text · Disabled fill is #E7E7E7 at 30% (not a token) and its line is #E2EAEC while all other light lines are #EFEFEF.
  • Missing variants: Dark Header has no Input Header; Child exists only for Light Text; Disabled only for Text and Input Text; no Dark Dropdown Active; no Tag or Dropdown disabled; no hover or selected row state.
  • Dark Header uses the Light checkbox (Mode=Light) in its hidden checkbox slot; Dark body cells use the Dark one. Built with Dark to match the body.
  • Header Filter is a loose 8×7 right-arrow vector, not a kit icon (kit has Navigation/Filter Arrow 10×10, pointing down). Inline SVG from the Figma path — atom variant missing in kit.
  • Header has two hidden, unbound icons (System-Status/Info, Info-Circle) with no property to show them. Not built.
  • Calendar-Input icon colour taken from the kit default (#343440); the hidden instance's own fill was not read. On Dark cells this is near-invisible.
  • Line height: 12px text is 16 in Figma vs 17 in .type-12-regular; Header 10 SemiBold is Auto (≈14) vs 12 in .type-10-semibold. Component tokens keep Figma heights.
  • Tag cell: Light frame is horizontal (gap 10), Dark is vertical (gap 2); a hidden Input Tag sits in the Light cells. Only the visible Multiselect Tag is built.
