Usage

Which list

  • Single-Info: one line per option.
  • Multi-Info: a second line and a tag per option.
  • Checkbox (Single-Info · Multiple): pick several.
  • Custom Add: the person can add an option that is missing.
  • Table: options with several columns, with Recent / Search / Selected layouts.
  • Dark: on the dark sidebar.

From the Figma variant names. Figma has no written usage guidance.

Behaviour

  • Single select: picking closes the list and fills the field.
  • Multi select: picking toggles the option; the list stays open.
  • Esc, Tab or a click outside closes.
  • Longer lists scroll inside the max height.
  • Custom Add: “Add new” opens a New Option row; Enter adds it, Esc cancels.

Placement

Directly under the field, left edges aligned (Dark Right variants: right edges aligned). Width follows Figma: 200 for lists, 400 for tables.

Accessibility

Listbox pattern

The list is role="listbox" (aria-multiselectable for multi); options are role="option" with aria-selected. Focus stays on the trigger, which points to the highlighted option with aria-activedescendant.

Source: WAI-ARIA APG Listbox

Keyboard

↓ / ↑ open and move, Home / End jump, Enter or Space pick, Esc closes and keeps focus on the field, Tab closes. The highlighted option uses the Figma Hover look. Table rows and dark plain rows have no hover in Figma, so they get a 2px blue outline added — not in Figma.

Checkboxes

Checkbox rows reuse checkbox.css. The native checkbox is hidden from assistive tech (aria-hidden, tabindex="-1"): the option's aria-selected carries the state.

Open issues

  • Two general menus exist. dropdown.html “Filter Dropdown Options” (4466:5808, Dropdown page) and these menus differ: Filter is 150 wide with a blurred search header, grouped options, 12 Regular #404040 text 8px apart with no row fill, selected = blue SemiBold text only, white 80% + blur and three off-token shadows. These menus are 200 / 400 wide (the field widths), 36px rows with padding 10, 12 SemiBold #313131, a hover fill #E9F1F5, a selected fill #F9FAFA, and tokenised shadows (--shadow-3 / --shadow-4). Dropdown Light · Single-Info is the general-purpose one: it is the list the Input – Dropdown Select Open variants instance, it matches the field width and it has hover and selected states. Filter Dropdown Options reads as a specialised filter menu (search + groups). Decide whether Filter becomes a “search + groups” variant of this component.
  • Duplicate code. input.css / input.js render their own copy of these lists (.pds-input__menu, .pds-input__dlist) for the Open variants, and the Table type shows a placeholder. Once this page is accepted, the Input Open variants could use menu.css. Not changed here.
  • Dropdown list · Theme=Dark (5992:8230) is identical to the light Search variant (white, light header). There is no dark table menu.
  • Table · State=Hover (6593:7502) is identical to Default. No visible hover for table rows.
  • Table · Selected rows show an unchecked checkbox in Figma, and Selection=Single rows also show a checkbox. Here the checkbox follows the selection (checked when selected) in both. Confirm whether Single tables should drop the checkbox.
  • Dark menus are four different builds. Single Left uses .Dropdown Option Dark rows (36 high, SemiBold, #D5DAF4); Single Right and Multi-Select Right use plain 12 Regular white text, right-aligned, 12 apart; Multi-Select Left uses dark checkboxes. Selected colour #9CD2FF in all. Four of the Single Left rows are 37 high (built 36).
  • No hover / disabled for light list options or dark rows (only the table cell has Disabled=Yes). Dark plain rows get an underline on hover/keyboard plus a focus outline added — not in Figma.
  • Off-token colours: #E9F4FE (selected row), #2A4255 (toggle label), #0078DD (active pill, 1 step from #0076DD), #737373 (ENTER hint), #484858 50% (dark pill).
  • Atom variant missing in kit: the “. Toggle” pills (.Active / .Inactive Toggle Tab) are not in toggle.css (its Toggle Tab is a segmented control), so they are built inside this component. The table Tag uses .pds-tag with a #EFEFEF fill override (Figma: Color=Purple with the fill overridden).
  • Line heights: Figma uses Auto (≈16 for 12px) and 16 for table text; built with .type-12-semibold / .type-12-regular (17) inside fixed 36px rows. Section / header 10px text is Auto (≈14) vs 12 in .type-10-semibold. Toggle text 10 Bold is 14 high in Figma (set to 14).
  • Multi-select field value: Figma has no Multiple field state for these lists. In Try it the field shows the picked labels joined with commas build choice — confirm; the Inputs Tag Input type is the alternative.
  • Scrollbar placement: Figma draws the 6px scrollbar over the table rows (x 389) and with a 30px top inset; the native scrollbar here sits beside the rows. Light Single / Multi-Info / Custom Add lists show no scrollbar in Figma; here they scroll past the max height with the Light scrollbar.
  • Contrast (deferred): hover fill #E9F1F5 vs white 1.14 : 1 and selected fill #F9FAFA 1.05 : 1 (the blue text carries Selected) · selected text #0076DD on #F9FAFA 4.33 : 1 and on the table #E9F4FE 4.06 : 1 (both below 4.5) · active pill white on #0078DD 4.44 : 1 · cell divider #EFEFEF 1.15 : 1 · passes: “ADD NEW” #376F99 5.39, ENTER #737373 4.74, header #005399 7.79, dark selected #9CD2FF on #24242F 9.56.
