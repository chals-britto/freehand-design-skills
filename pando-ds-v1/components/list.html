Usage

Figma has no usage text for these sets. What follows describes the components as built.

Pick a type

  • Standard — a card row with shadow; actions on the right.
  • Table Style — flat rows with a divider; a status on the right. Use BG=Alternate for striping.
  • Swappable — a row shell with any content inside.

Columns

Columns are List Column cells (list-column.css) in a fixed order. Columns 5–8 can be shown or hidden; hidden columns take no space.

Selection and expand

Show Checkbox adds the kit Checkbox as the first item. list.js marks the row aria-selected and fires pds-list-select. The expand icon fires pds-list-toggle; what it opens is up to the screen.

Accessibility

Checkbox needs a name

There is no visible label. Give the input an aria-label such as “Select Column 1” (the row’s first value).

Expand/Collapse

A real <button> with aria-expanded and an aria-label. Focus ring is added in review (not in Figma). Point aria-controls at the expanded content.

Info indicator

The red bar is colour only. Say what it means in text too (e.g. visually hidden “Has an issue”).

Hover is not a state for keyboard users

Hover only changes the fill. Options are always visible, so nothing is hidden from keyboard or touch users.

Contrast (for the accessibility pass)

Text on #EEF2F4 hover: #313131 13 : 1, #545454 6.9 : 1 — pass. Divider #EFEFEF on white 1.1 : 1 and indicator #D26568 on white 3.9 : 1 (non-text, under 3 : 1 / 4.5 : 1 targets for the divider). Action #376F99 on white 5.5 : 1.

Open issues

  • Hover does not reveal the right-side options: in Figma the Button Group / Status is visible in both Default and Hover. Hover only changes the fill to #EEF2F4. Built as Figma.
  • No selected-row visual in Figma (checkbox only) and no header checkbox, so no select-all. list.js sets aria-selected / .is-selected without styling.
  • Type=Swappable has no Hover variant; built without hover.
  • List Type=Table Style: Default has the 0-2-4-6% shadow (wrapper around .Table Style), Hover has none; the .Table Style set itself has no shadow. Built with --shadow for the List Default only.
  • .Table Style has Right-Action and Expand/Collapse booleans that no layer uses; only Right-Status is wired. Built: options slot takes either.
  • Standard Button Group shows 3 Action buttons (Figma hides 2 of the kit’s 5 by instance override); .Options in Right Action shows 1. The kit Button Group has no booleans for this — built by leaving buttons out.
  • Status in .Options in Right: #Status Small Brown is 85 wide but its label frame is 95 (overflows); label padding 2/10 vs kit 2/5. Kit status kept, width hugs.
  • Expand/Collapse icon has no defined expanded content; Navigation/List-Type icon SVG includes its own shadow — rebuilt as CSS drop-shadow with the same 0-2-4-6% values.
  • Hidden Columns 7–8 have no readable sample text (hidden instances); shown with the List Column default “Main Text”.
  • Error-Indication rectangle is 52 high fixed in Figma (57 rows in Table Style leave 5px); built full height.
  • .Base List has no children (an empty 48px row shell); built as an empty row.
  • Spacing between stacked rows is not defined (rows are single components); the page uses 10px for Standard and 0 for Table Style.
  • No dark theme, no disabled, loading or empty-list states. Narrow screens: the row keeps its column widths and scrolls sideways.
