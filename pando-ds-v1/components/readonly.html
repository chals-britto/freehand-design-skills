Usage

What it is for

Detail and Information: showing a value with its label where it can’t be edited. (Figma description)

Theme

  • Light on white and light surfaces.
  • Dark on the dark (sidebar) surfaces. Figma doesn’t name the surface; --dark-bg is assumed.

Not in Figma

No usage text, no layout for several pairs, no long-value or empty-value rule. See Open issues.

Accessibility

Plain text

It is static text, read in order: label, colon, value. Not focusable, no ARIA needed.

Contrast

  • Light #313131 on white: 13.0 : 1
  • Dark #D5DAF4 on --dark-bg: 8.2 : 1
  • Dark on white: 1.4 : 1 — wrong surface, don’t.

Open issues

  • Line height: Figma is 16px (label) and auto (≈16px) for “:” and value; the kit’s .type-12-* classes are 17px, so the line is 1px taller in code.
  • Several pairs: Figma shows only one line. No row, column or grid of pairs, no spacing between pairs, no label-column width — not built.
  • Long values: no wrap or truncation rule in Figma. In code the value wraps within its own column.
  • Empty value: no empty or placeholder state in Figma.
  • Dark surface: the Dark variant has no background in Figma; --dark-bg is assumed on this page.
  • The atoms audit calls the second row “faded/disabled”; it is Theme=Dark, not a disabled state.

Industry gaps — not added

  • Read-only form controls that stay focusable but can’t be edited — a field state, not this text line; the input read-only state is in Input. Carbon read-only states
  • Carbon: don’t use the read-only state for static information that has no enabled state — consistent with keeping this as plain text. Carbon read-only states
  • Top-aligned labels as the default; side labels only when space is short. This component is side-label only; no top-label variant. Fluent 2 Field
  • Short, sentence-case labels. Figma’s sample uses Title Case. Fluent 2 Field
