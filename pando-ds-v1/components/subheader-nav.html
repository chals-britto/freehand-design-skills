Subheader Menu

The subheader title opens a two-level flyout: Level 1 rows on the left, and on the right the Secondary and Tertiary rows of the open Level 1 item. Figma’s .documentation has no overview; its “Uses” text is quoted under Usage.

Try it

Click the title (or Enter / ↓). ↑ ↓ move, → or Enter on a row with a caret shows its children in Level 2, ← goes back, Enter picks a row and closes, Esc closes. Sample text is Figma’s own “Menu Option”, so the readout shows which row you picked.

Usage

Uses (Figma .documentation)

  • When Secondary item selected - Active Submenu is Secondary menu
  • When tertiary item selected - Secondary menu - Tertiary menu

Built as: the trigger shows the Active label; for a Tertiary row it shows “Secondary - Tertiary” (see Open issues).

Placement

Opens from the subheader title (Subheader molecule, “SUBHEADER ACTIVE ▾”). Figma’s .documentation says “NA” for overview and placement.

Accessibility

Navigation disclosure, not role=menu

The component is a <nav>. The title is a button with aria-expanded / aria-controls. Rows are buttons (or links with href) in nested lists; rows with a caret carry aria-expanded and control Level 2. The Active row has aria-current="true".

Source: WAI-ARIA APG — Disclosure navigation

Keyboard

Tab works as normal. Added: ↑ ↓ Home End inside a column, → / ← between Level 1 and Level 2, Esc closes and returns focus to the title. Keyboard focus shows the Hover look plus a 2px #0076DD outline (added in review — not in Figma).

Contrast (for the a11y pass)

Hover text #0076DD on #EEF2F4 is 4.02 : 1 (below 4.5); label #0076DD on white 4.53 : 1. Active vs Default differ by colour only (#0076DD vs #234357).

Open issues

  • No “open parent” state: Figma shows Level 2 filled but no Level 1 row marked. Built: the open parent has aria-expanded="true" only, no visual.
  • How Level 2 is chosen is not drawn. Built: click / → / Enter on a caret row; default = parent of the Active row, else the first caret row. No hover-to-open.
  • Trigger label after a pick is read from the .documentation text (“Secondary menu - Tertiary menu”); the separator “ - ” is literal. showValue:false keeps the label fixed.
  • Whether a Secondary row that owns Tertiary rows is itself selectable is not drawn. Built: selectable.
  • Trigger border #E2EAEC here vs #E9F1F5 on the Molecules Subheader Menu (same trigger, different stroke) — kept per file, via a token override.
  • No Disabled state, no max height / scroll (16 hidden row slots in Level 1, 9 in Level 2).
  • Row text line height: Figma auto 16 vs 17 in .type-12-semibold.
  • Hover text contrast 4.02 : 1; Active is colour only.
  • Component-set rows are 204 wide; inside the flyout they fill 216.

Industry gaps — not added

  • Fluent 2 asks to avoid nesting too many menus and to label the trigger — depth here is fixed at Level 1 / 2 / Tertiary. Fluent 2 Menu
  • APG disclosure navigation sets aria-current="page" on the link to the current page; rows here are buttons unless an href is passed. WAI-ARIA APG
