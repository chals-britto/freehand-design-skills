Usage

From Figma

Figma has no description or usage text for these components. Sample shows one road leg with Associated Picks, Vendor, Transit Time and ETA.

Building a route

Stack one Location Timeline per leg. The mode icon comes from the Indicator Icon family (Road in Figma). Use the Edit leg while a leg is being changed.

Edit meaning inferred from the variant name only — Figma does not explain it.

Accessibility

Structure

The rail, markers and mode icon are decorative (aria-hidden). Figma gives the mode no text, so the mode is not announced — open issue.

Read order

Pairs read label, colon, value, left then right, row by row. No interaction, nothing focusable.

Contrast

#404040 on the card (≈ #F6F9FB) 9.8 : 1; #313131 12.3 : 1 — pass. Edit rail #B5C3CB on white is 1.8 : 1 (non-text, below 3 : 1) — kept as Figma.

Open issues

  • Label Readonly Text is used with overrides the kit atom doesn’t have: label/“:” in #404040 (off-token, not --text-dark), and an italic “NA” value (Input/Regular/Italic). Atom variant missing in kit — built inside this component.
  • ETA value “NA” is #404040 SemiBold, while Vendor and Transit Time “NA” are #313131 Italic. Inconsistent empty-value styling — kept as Figma.
  • Line height: label is 16px in Figma, value “auto”; kit .type-12-* is 17px, so rows are 17 tall instead of 16.
  • Only one Location Timeline state (Default). No Edit Location Timeline, no hover, no selected, no first/last-leg treatment, no current-position marker.
  • Hidden layers in Figma, not built: a Header (“Domestic Haulage” stage label + empty Button frame), a third details row, and marker sub-layers (Outer Node #D9E6FF, Inner Node #2D0645, Light Opacity) — states they imply are not published.
  • Only the Road mode icon is shown; which Indicator icons are allowed per mode is not specified.
  • Mode icon has no text alternative in Figma; screen readers don’t hear the transport mode.
  • Edit rail #B5C3CB on white is 1.8 : 1 (below 3 : 1 for graphics).
  • Width: Figma root is 683 with the card 601; no min/max width or wrapping rule for long values.
