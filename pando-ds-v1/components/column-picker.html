Column Picker

A panel for choosing which table columns are shown, which are pinned, and their order. Three types: Toggle, Pin and Advanced.

Try it

Switch columns on and off, pin them, show or hide each header (Advanced), and drag the dotted handle to reorder. Keyboard: focus a handle and press ↑ / ↓. Changes apply immediately — Figma has no Apply or Reset. Column names are numbered here so the order is visible; Figma uses “Column Name”.

Usage

Types

  • Toggle — a switch per column shows or hides it.
  • Pin — a pin per column pins or unpins it.
  • Advanced — a switch per column, plus two View Header chips that each show or hide one header.

Behaviour

  • A hidden or unpinned column’s name turns grey.
  • Advanced: with the column off, both chips are disabled; switching it on restores them.
  • Drag the dotted handle to reorder.
  • Changes apply immediately. No search, Apply or Reset in Figma.

When (not) to use

No guidance in Figma.

Accessibility

Controls are buttons

Switch is the kit role="switch", named “Show {column}”. Pin and View Header are <button aria-pressed>. Chips are disabled while the column is off.

Reorder without a mouse

The handle is a button. ↑ / ↓ move the row, Home / End move it to the ends; the new position is announced politely. Added in review — not in Figma.

Source: WCAG 2.2 · 2.5.7 Dragging Movements

Focus

2px --pando-blue ring, offset 2, on handle, pin and chips. Added in review — not in Figma.

Open issues

  • Contrast (deferred): green names and pin #67AC5D on white 2.75 : 1; Unpin #234357 at 50% ≈ 2.7 : 1; Disabled chip #A3A2A2 2.55 : 1; drag dots #CBD4D8 1.5 : 1; the 8px subtitle is below readable size.
  • Line heights: Figma Auto (12 SemiBold → 16, 8 Regular → 11); kit .type-12-semibold is 17, .type-8-regular is 10.
  • Drag Indicator instance is 5 × 11 in .Column Toggle / .Column Pin and 7 × 11 in Advanced; the kit icon (7 × 11) is used for all.
  • Subtitle says “can display upto 10 columns at any instance”, but Figma has no state for reaching the limit; nothing is enforced.
  • Header button (Show Button, off by default): icon slot is Indicator Icon/Resize; Figma doesn’t say what it does or name it. Built with aria-label="Resize".
  • Advanced: the meaning of the two headers per column isn’t stated (both say “Column Name”). The hidden Checkbox in the row is not shown.
  • No hover, focus, dragging or drop-indicator states in Figma. No max height or scroll for long lists.
  • No single-pointer alternative to dragging (WCAG 2.5.7).
