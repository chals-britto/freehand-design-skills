Metrics + Widgets

Count tiles for the filter area: Metrics (small 70px tiles, pinnable or clickable), Widget Group (a labelled row of 2–6 clickable metrics) and Widgets (rounded count cards, light or dark, with an edit mode). Figma has no written description for these sets.

Usage

Which one

  • Metric · Clickable: a count that filters the list when pressed (Active = applied).
  • Metric · No Click / Pinnable: a count to read, which can be pinned.
  • Widget Group: 2–6 clickable metrics under one rotated type label.
  • Widget: a larger count card; Edit mode adds a drag handle, More actions and a pin.

Roles inferred from the Figma variant names; Figma has no usage text.

Composition

Top Filter (built later) places these inside its own background. Classes are self-contained (pds-metric, pds-metric-group, pds-widget) and only need icons.css and button.css.

Content

  • Label: one short line; longer text is cut off.
  • Numbers are shown as given (Figma samples: 08, 04, 080, 2000).

Accessibility

Buttons

A clickable metric has a full-tile <button class="pds-metric__hit" aria-pressed> named by the label and value. Pins are separate <button aria-pressed> above it (“Pin” / “Unpin”). Focus ring: 2px --pando-blue — added in review, not in Figma.

Icons

Indicator, risk and drag icons are decorative (aria-hidden). The risk state is carried only by colour and icon — give the label the meaning.

Rotated label

The Widget Type rail uses writing-mode, so the text stays real text for screen readers.

Open issues

  • Label text in Figma is “\nLabel” (an empty first line) at 10/100% (12/100% on Solid widgets). Built as top padding so the word sits at the same spot; the label styles don’t match .type-10-semibold (12px line-height, +0.5 tracking) or .type-12-semibold (17px).
  • Metric · Clickable · Hover hides the number, and its icon (“Indicator Icon/Dashboard/14px”) is an empty component — the tile shows only “Label”. Kept as Figma.
  • Metric · Clickable · Active fill and the Pin glyph are one-stop gradients (#3F6ABF); built as solid colour.
  • Many colours are not in tokens.css: #20354E, #3F6ABF, #18283B, #36577E, #B495F7, #325599, #CADCFF, #19A476, #484858, #0078DD (≈ --pando-blue #0076DD), #003D31, #FFE01B.
  • Widget shadow 0 4 20 at 1% is not one of --shadow-1..4 and is practically invisible.
  • Number and widget text styles (Bold 20 / 80%, Bold 24 auto, Regular 12 auto, Bold 8) have no type token.
  • More Actions in Edit widgets uses a 14px “No Circular / Icon / 14px” glyph; the kit has only the 10px Action icon action-more-actions — atom variant missing in kit (used the 10px glyph at 14).
  • The group dividers (“Line 140…”) carry a 125px background blur and an 8% drop shadow in Figma; not built (no visible effect on a 0.5px line).
  • Widget Group 2 Widgets uses sample “080” in the first tile, the rest use “08” — kept exactly.
  • Group sample: the 6 Widgets variant uses a detached “Widget Type” instance (not “.Widget Type”); same look.
  • Contrast below 4.5:1: “Label” white on Hover tile (#325599 40% on white ≈ 2.1:1); Dark widgets (#484858 30% on white) and Disable text #8A8A9E (≈ 3.4:1 on white); Glass Pinned label #006265 is fine. Dark and translucent widgets need a dark or image backdrop that this file does not supply.
  • Figma does not say whether one or several clickable metrics can be Active at once; each tile toggles on its own.
  • No disabled, loading or empty-value state for Metrics; no keyboard focus visuals anywhere.

  • Prefix / suffix slots for units — Ant Design Statistic (Figma has a hidden “Unit” layer on metrics and the hidden “%” unit on widgets)
