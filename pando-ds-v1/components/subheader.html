Usage

Placement

Main subheader to be placed on listing or landing pages. Any inside page will have a breadcrumb based subheader. (Figma .documentation)

Position

Used below header in either landing pages or inner pages. (Figma description)

Seen on the Figma page

Main at 1280 with Toggle and Buttons; 1440 with Buttons; Breadcrumb with no buttons. Read from loose instances, not added as rules.

Accessibility

Real controls

Menu, title, back and search are <button>s. The menu and back buttons have no visible text, so they carry aria-label (“Menu”, “Back”). The title opens a menu: aria-haspopup="menu" + aria-expanded.

Atoms

Breadcrumb is a <nav aria-label="Breadcrumb"> with aria-current="page". Toggle is a radiogroup with arrow keys (toggle-tab.js). Buttons as the Button atom.

Focus & contrast

Focus ring 2px Pando Blue — added in review, not in Figma. Contrast failures are listed under Open issues (fixes deferred).

Open issues

  1. Atom variant missing in kit: Breadcrumb has no Dark theme. The subheader re-colours the kit atom (#D5DAF4 / #8A8A9E / white) through its tokens.
  2. Dark Breadcrumb border is #18283B (not in tokens.css); Dark Main uses #234357. Two different dark borders.
  3. Contrast: Search text #8A8A9E on #393945 ≈ 2.9 : 1; Dark divider lines are decorative. Light “Previous” #545454 on white passes.
  4. Dark Search icon colours not read (the instance exposed no vectors); built with the Light two-colour icon (#0076DD / #234357), which is nearly invisible on #393945.
  5. Toggle icons: Figma uses “Menu/Payments” + “Menu/Rules”; the kit manifest has no Menu/Payments, so the Toggle Tab kit’s menu-india-payments is used.
  6. Boolean coverage differs by variant: With Toggle only on Light Main / 1440 / Light Breadcrumb; Show With Menu only on Light Breadcrumb; Dark and Back have no toggle.
  7. Small Figma differences not reproduced: Size=Main has 0.5px top/bottom padding; left section right padding 20 (Light) / 15 (Dark); Breadcrumb right group has an extra 10px left padding. None is visible because the bar is space-between.
  8. Size=1440 is the same layout as Main at 1440 wide — a width, not a variant. Kept as published.
  9. Title dropdown has no open/hover/active state in Figma; the menu it opens is “Subheader Menu” (Dropdown page), built separately.
  10. No hover, focus or pressed states for menu, title, back or search in Figma. Focus ring added in review.
  11. Title line-height is “auto” in Figma (19px for 14px Open Sans) — matches --type-14-semibold.
  12. px values not on the spacing scale: 20 (gaps, right padding), 60 (menu area), 50 (height); icon boxes 8×5 and 8×14.
