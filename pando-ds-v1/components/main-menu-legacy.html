Usage

One level

A flat list of labelled modules (Figma sample: Dashboard, UDM, Reports, Rate Cards, Admin Settings). No fly-out and no sub-pages.

User on top

The avatar, name, role and Log Out sit above the list; × closes the menu.

For new screens

No usage text in Figma. If the menu is no longer used, prefer the New Main Menu (to be confirmed).

Accessibility

Structure

<nav aria-label="Main menu">. Items are links with visible labels; × is a button labelled “Close menu”; Log Out is a button. The avatar is decorative (the name is next to it).

Current page

The current item gets aria-current="page" and the .Menu-Item Active fill.

Keyboard

Close, the item list and Log Out are one Tab stop each. ↑ / ↓ wrap, Home / End, Enter / Space follow the link. Esc closes the menu and returns focus to the opener. Added in review — not in Figma.

Open issues

  • Legacy — superseded by New Main Menu? Confirm whether still used.
  • Compared with New Main Menu: Old Menu is a single 240px panel with text labels and one level; New Main Menu is a 60px icon rail with a 250px fly-out and three levels. Both use the same .Menu-Item (Old Menu turns on its hidden “Text” label). The user block is on top here and at the bottom there; Log Out is a full-width text bar here and a 24px icon button there; the avatar fill is #FFFFFF here and #EEF2F4 there. Module set and icons differ (Dashboard, UDM, Reports, Rate Cards, Admin Settings vs Analytics … Settings).
  • In Figma each .Menu-Item stays 60 wide and the label overflows it, so the Hover / Active fill covers only the icon square. The kit stretches the item to 240 so the whole row is the target and takes the fill.
  • Item label text is the .Menu-Item “Text” layer, hidden in the component and shown only in this menu; it is a sample override (#376F99 on white ≈ 5.4 : 1, passes).
  • No current/selected item in the Figma variant; the kit uses the shared .Menu-Item Active fill (#F3F6FC on white ≈ 1.1 : 1 — below 3 : 1). Hover fill #E7E7E7 @ 30% is also ≈ 1.1 : 1. Kept as Figma.
  • Log Out is a plain group (rectangle + text) with no hover or pressed state in Figma; built as a button with no hover.
  • Close has no hover state in Figma. Navigation/Close-Tag is 14 × 14 here; the kit icon is 12 × 12 and is scaled to 14.
  • Line heights: name 12 “auto” (16) vs .type-12-semibold 17; role 10 “auto” (14) vs .type-10-semibold 12; Log Out 12/16 vs .type-12-regular 17 — Figma values kept.
  • Hidden layers not built: “Other Details” text under the role and 9 hidden .Menu-Item instances.
  • Item list sits 8px short of the 718 frame (152 + 558); the kit lets the list fill the remaining height and scroll.
  • No focus states in Figma (focus ring added in review).
