Filter By

Pill-shaped filters that sit in a filter bar above a table or list: a label, a colon and the applied value. With the bar, the collapsible More Filters group, the inline Data Selection dropdown and the date, time and metrics read-outs from the same Figma page.

Try it

Open each filter and pick a value: the pill turns Filled. The toggle filter is Filled when it says Yes. Open More Filters (funnel icon) and press Reset to clear every filter in the bar. Dates open the kit Calendar; the range arrows move the range by its own length. Option lists are the kit Filter Dropdown with its Figma sample options.

Usage

Parts

  • Filter By — one filter. Type Dropdown (pick from a list), Search (pick after searching), Toggle (on / off).
  • Dropdown Filters — the row that holds the pills.
  • More Filters — a funnel button that opens extra filters inline, with Reset and close.
  • Data Selection — a bare text dropdown, with or without a label.
  • .Date and Time — date, date range, countdown and the “selected” metrics read-out.

States

  • Empty: the value slot shows “Select” or “Search” in italic.
  • Filled: the applied value in blue (yellow on dark).
  • Hover: whole pill tints.
  • Figma has no pressed, focus, disabled or open state for the pill.

Not in Figma

Figma has no usage notes on this page. The behaviour here (list opens under the pill, Reset clears every filter in the bar, range arrows move by the range length) is the build’s reading of the components and needs confirming.

Accessibility

Real controls

Dropdown, Search and Data Selection pills are <button>s with aria-haspopup / aria-expanded (set by the kit dropdown). The Toggle pill is a group holding the kit role="switch". Dates open the kit Calendar as a dialog.

Icon buttons are named

Funnel: “More Filters” (the Figma link text). Close ×: “Close”. Range arrows: “Previous” / “Next” (added — not in Figma).

Focus

Focus ring 2px --pando-blue, offset 2 — added in review, not in Figma. Arrow-key navigation inside the option list is deferred with the kit dropdown.

Open issues

  • Dark Filled and Empty: the caret is #393945 on a #393945 fill (1 : 1) — it is invisible. Kept as Figma.
  • Contrast (deferred): dark Empty “Select” #8A8A9E on #393945 3.37 : 1; dark Hover text #313131 on #8A8A9E 3.85 : 1; light search icon #A3A3A3 2.52 : 1; Time value #D26568 on white 3.62 : 1; Filled blue on Hover fill 3.71 : 1.
  • Off-token colours: dark pill border #484858, dark value #FFE01B, Data Selection / date value #18283B, date label #20354E, calendar icon and metrics label #36577E.
  • Line heights: pill text is 11 / 16 (kit .type-11-* is 15); Data Selection and date values are 14 / 10 — tighter than the font size; date label 10 / 10; Time value Auto (19). Built as Figma.
  • Open Sans Italic (Empty value) is not loaded by tokens.css (400 / 600 / 700 upright only). This page loads it; products must too.
  • Atom variant missing in kit: Metrics uses Tag Small · Filled · Purple at 17px tall with 12 SemiBold text; kit Small is 15px / 10 SemiBold. Overridden inside .pds-filter-date__metric.
  • The remote “Filter Dropdown” inside More Filters is hidden and its contents can’t be read; it is 110 × 10, the same size as Data Selection Default, so it is assumed to be that.
  • Figma has no open state for any pill, no gap between pill and list, and no Apply. The list opens 4px under the pill and applies on pick — to confirm.
  • Range arrows (Right & Left Navigation): Figma doesn’t say what they do. Built to move the range by its own length.
  • Figma sample “01 Jan '24 - 07 Jan ‘24” mixes a straight and a curly apostrophe; picked dates use straight ones.
  • Reset copy: More Filters says “Reset”, the .Date and Time instance says “REset”; both render uppercase in the kit Text Button. Reset on a date returns it to its first value (Figma has no empty date).
  • Toggle type exists only in Light; Search Hover only in Light.

Industry gaps — not added

  • Count of applied filters on the closed More Filters button, and clearing them without reopening. Carbon · Filtering
  • “Clear all” per category and across categories; batch “Apply filters” when several selections reload slow data. Carbon · Filtering
  • Dismissible applied-filter tags that wrap rather than truncate. Fluent 2 · Tag
