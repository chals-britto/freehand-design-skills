    Usage

    Building a timeline

    • First row: --first. Last row: --last. Rows in between: no location class.
    • Type: Default (happened), --estimated (expected), --done (completed).
    • --issue turns the marker red/orange; add the SLA line under the text.

    Text slots (Figma properties)

    • Date · Time · Main Status (heading) · Description · Secondary Text (small).
    • Link line and SLA are optional. The SLA boolean defaults to on in Figma but is hidden in every Issue = No variant.

    Edit

    • Edit replaces the description, link and small text with a kit Inline input (225 wide). The SLA line stays.
    • Figma gives no save / cancel for Edit.

    Accessibility

    Structure

    Render a timeline as an <ol>, one <li class="pds-event-timeline"> per event. Put the date/time in a <time>. The rail and marker are aria-hidden.

    Meaning not only in colour

    Issue, Estimated and Done differ only by marker colour / dash / check. Give each row a visually hidden status word (e.g. “Issue”, “Estimated”, “Done”). Added in review — not in Figma.

    Open for the accessibility pass

    SLA unit #FF0000 on #FFEAEE 3.5 : 1 · “SLA BREACH” #E25757 on white 3.7 : 1 · rail #F2E7FE on white 1.1 : 1 (decorative). 8px text is below a readable size. Kept as Figma.

    Open issues

    • Atom missing in kit (remote library): Unit/Small — built as .pds-event-timeline__sla-unit. card.css has .pds-card__unit but it is fixed 150 wide with 12px text, so not equivalent.
    • Atom variant missing in kit: remote Text Input Field “Input Inline, Empty, Medium (No Border)” shows a dashed #B5C3CB border and #F9FAFA fill at rest. Kit Inline is borderless and white at rest — kit input reused with a scoped override.
    • No type class for 8px Semibold All Caps (SLA). Date is 10 semibold with no tracking and line-height 14 (.type-10-semibold is 12 + 0.5 tracking). Heading 12 semibold line-height 16 vs .type-12-semibold 17.
    • Estimated dash: the 13px top line has ≈2.2px dashes, the long line ≈3.9px (outlined vectors). Built as one 4px / 4px pattern.
    • Edit is “Issue = Yes” in Figma but keeps the purple marker; Issue = Yes Default hides the link. Confirm what Issue means.
    • Hover in Figma renders the link as plain text (no Link frame / New Tab icon); same look.
    • Fill style named “Accent/Light-Highlight-#EFF3F5” is actually #E9F1F5.
    • The Text Input in Edit is 225 wide while the text column is 251; built at 225.
    • No focus, selected or disabled states in Figma; link hover underline and focus ring are added in review.
    • Contrast below 4.5 : 1 — see Accessibility.
