Modal

When performing a sensitive action, a modal will appear to request your confirmation. This might be referred to as a popup, prompt message, or confirmation dialog.

Usage

Uses

  • Dark theme — CTA / confirmation triggered from the overall event / transaction level.
  • Light theme — triggered from an inner section of the page.

Placement & convention

  • Overlay on the screen.
  • If triggered by a fixed-position CTA, the modal appears directly over the CTA or at the top-left corner.
  • All other cases (trigger in a scrolled position): centre of the screen.

Interaction

  • Closing the modal: click the close (×).
  • CTA action (depends on the context).
  • Animation: instant.

Close button vs icon

  • A close icon should be available for non-blocking modals.
  • A cancel button should be provided when users need to discard a workflow-based action.
  • Optional or non-workflow modals may include either a close icon or a cancel button, but not both.

Accessibility

Dialog semantics

role="dialog", aria-modal="true", labelled by the heading and described by the message. modal.js sets these.

Keyboard & focus

  • On open, focus goes to the first field, else the first action (Cancel).
  • Tab and Shift+Tab stay inside the modal.
  • Esc closes. Focus returns to the trigger.

Not in Figma — required by the build task. Matches Fluent 2 Dialog and Carbon Modal.

Open issues

  • The “Close Button vs Icon” note says either a close icon or a Cancel button, not both — every variant has both (Persistence defaults to true).
  • Heading is 14/16 in Figma, .type-14-semibold is 14/19. Message is 12/auto (≈16), .type-12-regular is 12/17. Slot text 12/16. Rendered modals are a few px taller than Figma.
  • Button gap differs per variant: Light 10 (overrides the Button Group's 20), Dark Text / Text with Options 20, Dark Swappable 10 and built from loose “Secondary” / “Primary” Dark components, not a Button Group.
  • Dark Swappable keeps the light slot (#EEF2F4, #000 text) on the dark box. No dark slot.
  • Slot text is #000000 (off-token), fixed 150 wide. The refresh-line placeholder icon is not in the kit icon set (atom variant missing in kit — inlined).
  • Light Text with Input stretches Input - Text Standard (200) to 320. Dark Text Area is 310 in a 320 column. “Text with Options” holds a text area, not options.
  • Kit Text Area Empty shows no text; the live one here shows typed text with an empty placeholder.
  • Dark primary label is lowercase “confirm” in Figma (rendered uppercase).
  • Radius 2, gaps 16 and 8 are not on the spacing / radius scale.
  • No sizes, no scrolling body, no loading / error state, no danger variant (the Delete example uses Secondary Red).
