Usage

Usage text

Figma has no description or usage text for this set. Used by Subheader and Sort-1 (molecules inventory).

Behaviour

  • One option is always selected.
  • Click selects; arrow keys move and select (wraps); Home / End.
  • Description type: only the selected option shows its label; the others show an icon or a number.
  • Tab 3 is on and Tab 4 off by default (2–4 options).
  • No hover, focus or disabled state in Figma.

Related

The Atoms Toggle Tab (.pds-toggle-tab) is an older, square-cornered 2-option segment with different dark colours. Tab Group switches panels (tablist); this set picks a value or view in place (radiogroup).

Accessibility

Roles

role="radiogroup" with an aria-label (or aria-labelledby the description); options are role="radio" buttons with aria-checked. toggle-tab.js fills in missing roles.

One tab stop

Roving tabindex: only the selected option has tabindex="0". Arrow keys move and select.

Names

Icon-only options need aria-label. In the Description type each step keeps its label in the DOM (visually hidden until selected), so it is always named.

Focus ring

2px solid --pando-blue, offset 2px. Added in review — not in Figma.

Open issues

  • Naming: the Atoms kit already owns .pds-toggle-tab and --toggle-tab-* (toggle.css), so this molecule uses .pds-toggle-tabs / --toggle-tabs-* / pdsToggleTab.
  • Relation to the Atoms Toggle Tab: same idea as this set's Type = Toggle Tab, but the atom is radius 2 with a 1px inside border and fixed 69px options, and its dark version is #484858 @ 50% with a #D9E6FF active option; here the container and active option are pill-shaped (radius 12, inactive option radius 2), the border is outside, and dark is #484858 @ 30% with the same blue active option as light. Two sources disagree — pick one.
  • Relation to Tab Group (tabs.*): different pattern (tablist + panels, underline indicator). Not affected.
  • Two blues: Single Selection and the Description type use #0078DD (“Highlight/Blue-Dark”, not in tokens.css); Toggle Tab uses --pando-blue #0076DD.
  • Off-token: description text #2A4255 (unstyled), dark container #484858 @ 30% (unstyled; the atom uses 50%), #8A8A9E @ 10% border.
  • Type = Single Selection exists only for Selection = Option 1 (no Option 2 / 3 variants); built from the .Option base. Type = Toggle Tab exists only for 2 options. Dark exists only for Toggle Tab.
  • Active Single Selection option is SemiBold, inactive Regular — widths 70 vs 69, so the row shifts by 1px on selection. Light Toggle Tab active is Regular; Dark .Option Active is Regular too.
  • Icon: Figma uses a remote Menu/Payments (2427:9604). Not in the kit manifest by that name; built with the kit's Menu/India Payments (same ₹ notes drawing, 21 viewBox). .Toggle Base exposes an icon swap; samples use Payments + Rules.
  • .Option “Show Icon” (Indicator Icon/Details 14, hidden) exists only on the Dark variants; the icon colour inside the blue option is not specified — shown in its drawn colour --pando-dark.
  • .Individual Tab has no Icon · Active variant; when a step is selected it always becomes the text pill.
  • Line-height: Figma auto (≈16) for 12px; .type-12-* is 17, so a component token --toggle-tabs-lh: 16px keeps the 24px height.
  • Missing states: no hover, focus, pressed or disabled in Figma. Focus added in review.
  • Contrast (deferred): Toggle Tab light inactive frame #E2EAEC on white 1.22:1 (boundary only, WCAG 1.4.11). White on #0076DD 4.53:1, on #0078DD 4.44:1 (below 4.5). Single Selection inactive border #B5C3CB on white 1.81:1. Description type inactive circles rely on a 10% shadow only. Icon type active fill #E2EAEC vs white 1.22:1 — the selected icon tab is hard to tell apart. Dark Toggle Tab drawn on white in Figma: white labels on #484858 @ 30% over white 1.67:1 (on --dark-bg 10.5:1).
  • No Figma usage, description or Do / Don’t text for this set.
