Accessibility

Filter button is a button

Use <button type="button">. Give it a name that includes the count, e.g. aria-label="Filter, 0 applied". Focus ring is added in review — not in Figma.

Figma does not say what Active means (open panel? filters applied?). Once known, expose it with aria-expanded or aria-pressed.

Chips are static text

The chips have no remove × and no click state in Figma, so they are plain <span>s in a list. Wrap the row in a container with role="group" and a label such as “Applied filters”.

Open for the accessibility pass

Chip border #EFEFEF on white is 1.1 : 1; Dark Blue chip border #495A6B on #20354E is about 1.9 : 1 (non-text needs 3 : 1). The Default button #234357 on the Dark Blue surface #20354E is about 1.1 : 1. Kept as Figma for now. Text colours pass.

Open issues

  • Figma marks this page OLD — confirm whether it is still in use.
  • Compare with Filter By (built in parallel): filter-by.md did not exist yet, so this is preliminary. Filter By is a bar of label : value dropdown pills (caret, Light/Dark, toggle type, More Filters, date/time). Filter Row is one Filter button with a count plus static chips, no dropdowns. Same purpose, no shared parts (only the #EFEFEF chip border). If Filter By replaces it, Filter Row can be retired.
  • Button content overflows. The button is fixed at 84px but its content (icon 10 + 8 + label 37 + 8 + badge 16 = 79) plus 20px padding needs 99px. Clip is off, so the badge ends ~5px past the right edge — visible on Active, where it crosses the border. Kept as Figma.
  • Atom variant mismatch — Badge. The button uses Badge / Type=Count, Size=Small, Color=Blue; here it is blue #0076DD with white text, while the Atoms kit .pds-badge--count is grey #B5C3CB / #313131. Reused the kit class and recoloured it with component tokens.
  • Badge sample text is “0 ” (trailing space) in Figma; rendered as “0”.
  • Remote “Filter” chip has no kit equivalent (Filter / Type=Tag-Light, sibling Type=Tag-Dark). Closest kit tag is Count (22px, 2px border) — not the same. Built inside as .pds-filter-row__filter.
  • Dark Blue uses Tag-Light with overrides (border #495A6B, white text), not the Tag-Dark variant. The chip’s #E3EFFA fill is hidden in both themes.
  • Dark Blue theme has no fill. It relies on a loose page rectangle #20354E (off-token; also off-token in Metrics). The Filter button is identical in both themes.
  • Line heights: button label 12/16 (kit .type-12-regular is 12/17); chip 11/16 (kit .type-11-regular is 11/15). Figma values kept in component tokens.
  • Missing states: no hover, focus, disabled or pressed for the button; chips have no remove ×, hover, overflow (“+N more”) or clear-all. Focus ring added in review — not in Figma.
  • Documentation card is stale: the page’s .documentation instance carries the Calendar text.
  • Off-token colours: #495A6B, #20354E.
